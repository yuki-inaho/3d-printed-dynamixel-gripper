# Add-on Fixture Checks

Identify the host by occurrence, frame and physical context. A photograph supports
identity, not measured dimensions. Use authorized nominal CAD dimensions to design;
keep physical tolerance/retention checks at trial assembly. Prefer a structural
web to a flexible fork, moving bearing, cover or connector. State clamp force direction.

## Connected Parts and Obstacle Types

A valid Boolean union may still contain disconnected solids. Check solid count
after export/re-import. Edge-only contact is not an integral load-bearing joint.
Change the geometry, not the assertion.

Volume tests require volumetric operands. Supplier STEP may include shells or
faces. Never silently skip them or interpret kernel failure as zero intersection.
Disjointness from an inflated enclosing box is a conservative clearance certificate;
record that method separately. If the box is not separated, the result is unresolved,
not an interference-free solid. Do not heal supplier models implicitly.

## Assembly Stages

Check bench preassembly, host mounting, downstream assembly and service separately.
Keep an installed-state failure even when deliberate preassembly works. Include
all parts present at each stage, not only a bare bracket.

Model working end, shaft and handle of tools. A tubular nut driver needs a cavity
for the protruding screw: a solid cylinder falsely rejects that intended space.
Never omit neighboring hardware to hide real collisions. Tool dimensions remain
assumptions until purchased tools are identified. Approach clearance does not prove
engagement, wrench sweep, hand room or available tightening torque.

Sampled insertion paths are not continuous sweep proofs. Add actual cables and
connectors when known. Hole alignment does not prove stack thickness, thread
engagement, head support or electrical isolation.

## Review

Inspect XYZ orthographic and assembly views of the hashed output. Extra holes in a
supplier device may be an alternate pattern; measure before declaring misalignment.
Keep the selected pattern explicit. Use the independent browser skill instead of
embedding application-specific browser operations in this CAD workflow.
