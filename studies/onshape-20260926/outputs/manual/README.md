# スクリーンショット付き作業マニュアル

- `MANUAL.html`：ブラウザで開く。画像をクリックで拡大。画像を内包しているため、このファイル単体で読める。
- `MANUAL.pdf`：A4・25ページ。配布・印刷用。
- `MANUAL.md`：編集用原稿。画像は同じフォルダの `images/` を参照する。
- `images/`：本文20図、追加証拠2枚。原画像は変更せず、必要な画面範囲をブラウザで撮影した。
- `verification.json`：レイアウト・画像・変換手順の検証記録。

再現用スクリプトは上位フォルダの `reproduce/`、URDFは `robot/` と `rebuild/robot/`。全てまとめた配布物は上位の `onshape-robot-bundle.zip`。
