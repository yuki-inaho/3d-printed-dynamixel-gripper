# C92-J28 改訂作業書

## W00 / 変更要求と失敗原因
ユーザーは、小型の駆動部は維持しながら、グリッパーとして物をつかめる大きさの爪を許容しています。
C7では私が決めた「全奥行62 mm以下」を爪先まで一律に課し、爪の前後長12.1 mm、接触パッド奥行3 mmまで削りました。外形と開口の数値を満たしても、物を差し込んで保持する接触面が不足するという仕様の欠落でした。
この改訂では「駆動部の小型化」と「把持部の有効寸法」を別の要求として扱います。

## W01 / 固定するもの
単一XL430-W250、背面直立、左右対称の平行開閉、全幅92 mm、本体高さ、クランク・リンク寸法、角度25〜135°、ホーン取付、枠、押さえ、支点、既存締結品を維持します。金属の案内棒・別体カラー・直動軸受は追加しません。標準ねじ・ナット・座金は既存どおり使います。カメラ・腕接続は今回の変更対象外です。

## W02 / 新たな寸法と改訂理由
爪の前後長は28 mm（12.1から+15.9）。高さ36 mm、把持板厚5 mmを維持します。接触面を貫通する窓はなくし、厚さ1 mmのゴム等のパッド28×20 mmを左右に設けます。パッド全域を樹脂板で裏打ちします。接触面積の増加を、そのまま摩擦力や耐荷重の増加とは扱いません。
爪の上下の根元に補強リブを追加します。既存のねじ座面・穴・取付面は動かしません。
左右スライダの上下シューを内側へ4 mm延ばし、移動方向の支持長を14から18 mmにします。外側へ延ばさず、枠幅と開口を維持します。閉じ位置で相手のシューとの間隔を検査します。
奥行62 mmの旧制約は、ユーザーの爪寸法見直しに伴い改訂します。新たな全体上限は78 mmで、後方の駆動部は不変とします。旧検査を合格させるための無断変更ではなく、この要求変更を明記したうえでの別仕様です。

## W03 / この改訂のCAD完了条件
1. 変更対象は左右の爪・左右スライダ・左右パッドだけ。枠、押さえ、駆動、サーボ、締結品の形状と配置をC7と比較する。
2. 全幅92 mm以下、全高64 mm以下、全奥行78 mm以下。パッド付き最大開口48 mm以上、閉じ位置0.3〜1.5 mm。従来の開口曲線と左右対称性を維持する。
3. パッド28×20 mmの全域に5 mm厚の連続した裏打ちがあり、10/25/45 mm幅の試験形状が新しい把持空間へ入る。これは剛体の接触幾何であって実物保持の保証ではない。
4. 25〜135°を0.5°刻みで、締結品込みの全モデル体積干渉を検査する。許可領域・0.01 mm³閾値をC7から緩和しない。変更部の接近距離も別検査する。
5. 90°姿勢で既存の工程別挿入・工具軸検査を新形状に対して再実行する。
6. 新しい4個のSTLと3姿勢の組立STEPを保存し、再読込みして形状・部品数・寸法を照合する。
7. 案内と爪根元の荷重を、仮定を明示した静力学で比較する。材料の実測値がない状態で強度・耐荷重合格を宣言しない。
8. 本体幅・開口を悪化させる変更、パッド裏の窓、シュー同士の接触、旧12.1 mm爪への退行を独立に拒否できる検査を入れる。

## W04 / 現物の完了条件とは分離
この作業では印刷・実組立・荷重・摩耗を実施できません。実物の認定は未実施として残します。新しい把持面の中央と先端側の両方に外部荷重をかけ、滑り・たわみ・案内のこじれ・解放動作を調べる必要があります。サーボの定格やPWM値から把持力を保証しません。

## W05 / C8不合格とC9への修正
C8の221姿勢の体積干渉は0件でしたが、別に実行した距離検査で、新しく内側へ延ばしたシューとクランクが107.5°付近で0.1773 mmまで接近しました。要求の0.3 mm未満なので、C8は不合格です。「干渉0」を隙間検査の合格に読み替えません。
C9では延長した内側4 mm部分の内縁だけを上下に0.5 mmずつ逃がしました。押さえの下にある長さ18 mmの支持面（Y=19〜21.7）は維持し、枠・外幅・開口・ねじを変更していません。距離の合格閾値も維持しました。
変更前の結果と生成元をreports/iterations/C8に保存し、C8形状を戻すと距離検査で拒否される負例を追加しました。C9の形状で全域検査・組立・出力・保存後検査をやり直します。

## W06 / C9の再検査結果
全221姿勢のモデル化した全部品で、不許可の交差体積が0.01 mm³を超える組合せは0件でした。45姿勢で変更部を含む異なる可動群の距離を検査し、指定嵌合を除く最小測定距離は0.400 mmでした。延長シューとクランクは95〜125°を0.1°刻み301姿勢でさらに調べ、最小測定距離は0.400 mmです。
新形状で9挿入経路、18工具軸を確認し、標準9 STL、3姿勢の組立STEPを保存後に読み戻して照合しました。56件の旧部品・配置照合により、変更していない部品の据置きを確認しました。
パッド全域の裏打ち、箱10/25/45 mmと円柱直径25 mmの接触空間、6種類の誤形状の拒否も確認しました。

## W07 / 荷重レビューの結論
爪の延長は無償ではありません。片爪5 Nを仮の比較点にすると、パッド中央の案内まわりのモーメントは旧107.5から139.5 Nmmへ増え、パッド前端では189.5 Nmmです。支持部を長くしたことは設計措置であって、摩擦や強度の実機合格を意味しません。材料特性や摩擦係数が未確定なので、耐荷重を設定せず、中央荷重・先端荷重・解放の確認を現物受入へ残します。

## W08 / 出荷データの区別
最終版はPG3-C92-XL430-J28-C9です。C8の不足隙間の結果は歴史記録で、最終合格の根拠にはしません。最終の検査ファイルは同じ版番号と生成元ハッシュを要求します。全体寸法だけでは把持機能の確認にならないため、今後もパッド有効面・裏打ち・物体進入空間・荷重点の確認を独立項目として残します。
