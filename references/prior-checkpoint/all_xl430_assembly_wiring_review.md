# 全XL430アーム: 組立・締結・工具・配線の確認

更新: 2026-09-22。これは検証記録であり、製作承認や通電手順ではない。

ユーザー確定条件: 全モーターXL430、給電基板E148、当面は安定化電源、リンクはPLA。
ケーブル仕様・電源型番・可動域・搭載荷重は未確定。中心ボルト・ワッシャー・工具は
未購入であり、以下の仮寸法は購入推奨や実物の確認済み寸法ではない。
追加許可: 必要な締結箇所に限り、リンクの穴径も変更可能。元輪郭を保持し、穴位置・支持幅と
合わせて変更範囲と理由を記録する。実ねじ選定・深さ確認後に適合径を確定する。
全穴の一律拡大、無関係な形状変更、モーターの追加工の許可ではない。

## 目的と変更範囲

ユーザーの方針は全モーターをXL430に統一すること。目的は、CAD上で並ぶだけでなく、
部品を挿入でき、ボルトを適切に締められ、リンクを締め付けずに支持し、配線後も
工具が入り、可動時にケーブルを挟まないアームにすることである。

既存形状を勝手に作り直さない。肩の応急アイドラー、参考ワッシャー・ボルト、配線の
仮包絡、工具の検査包絡は未承認の全XL430アセンブリを参照する別候補である。
追加調査でJ4の配置バグだけを補正した別runを生成したが、既存リンクの適合問題は残る。
混在モーター版の合格を流用しない。

**3面の一致はねじ締結・印刷・実機支持の合格ではない。** 接触面積に強度の合格閾値は
設定していない。ケース側全締結、実ねじ深さ・頭・工具、実アイドラの有無、PLA公差/強度は未承認。

## ボルトを何で、どのように締結するか

### 旧一体つば候補の中心ボルト

以下の頭位置・工具包絡・寸法連鎖は旧候補に限定する。

| 項目 | CAD上の条件 | 実機に対する扱い |
|---|---|---|
| ボルト | 参考M3 x 12、頭径5.5、高さ3 mm、ねじ山なし | 購入仕様は未確定。実受けねじに適合することを確認して選定 |
| 工具 | モデルの二面幅2.5 mmに対応するストレート六角ドライバー | 実ねじの駆動部と工具寸法の照合が必要。L字レンチは別途掃引が必要 |
| ワッシャー | 金属、外径12・内径3.4・厚さ1 mmの参考形状 | パイロット端面に着座させ、可動リンクを挟んで固定しない |
| 挿入方向 | グローバル+X側から-X方向 | 反対側の出力ホーンからではなく、アイドラー側の中心へ挿入 |
| ボルト頭の外面中心 | (31.50, 116.60435, -46.63671) mm | STEPアセンブリ座標。ユーザー視点の左右とは別 |
| 軸方向の寸法連鎖 | 首下からCAD穴入口まで8.45 mm、穴への重なり3.55 mm、底余裕0.95 mm | **穴への重なりは実ねじの有効掛かり長さではない** |
| 締付トルク・ねじ受け | 未確定 | メーカー仕様と実物確認が必要。数値を仮定して締めない |

参考工具は軸長60 mm、柄径24 mm、柄長80 mm、引き抜き40 mm。
六角軸の外接円に半径方向1 mmを追加し、柄の半径には指用の仮余裕15 mmを追加した。
全回転と軸方向移動を含む円柱包絡であり、工具そのものの製品CADではない。
工具軸包絡はX=31.5..131.5 mm、握り包絡はX=91.5..211.5 mm。
この範囲で保持ソリッド・仮配線との体積交差は0。相手部品を丸ごと除外していない。
ビット先端がソケット内部で適切に掛かること、作業台や人の姿勢は未検証。

## 組立順序の拘束

従来記載していた「つばを先に入れ、後でモーター/リンクを入れる」案は、調べた単純経路では
不成立だった。実物の操作手順として使わない。以下は新候補のCAD経路定義であり、実機指示ではない。

1. 単体の元リンクを初期固定物とし、モーターを最終位置から(2,0,-70) mmの位置に置く。
2. (2,0,0) mmまで動かし、最後に(0,0,0)へ戻す。モーターは工場サブアセンブリのまま。
3. 金属筒→PLA案内筒→ワッシャー→ボルトの順に、各々最終位置から+X40 mmの位置から挿入する。

設置済み部品は自動で全て障害物に含める。任意の除外キー、順序逆転、最終部品不足は拒否する。
ねじ締結と工具の動作はこの位置移動だけでは検証していない。残りのアーム部品、全締結、
ケーブル接続/固定と工具の競合、予定可動域、無理なく組める実寸法の検証が揃うまで未承認。

## 配線の設計条件

CAD内の6台は、根元からベース、肩、肘(`J4`)、延長(`J6`)、手首(`J3`)、
グリッパー(`J5_GRIPPER`)。この`J*`は変換スクリプトの識別子であり、実機のモーターIDではない。

ケーブルは各XL430の実ヘッダー配置行列から位置と向きを取得する。中心ボルトの穴を
配線穴に兼用しない。仮束径6 mm、仮曲げ半径15 mmで外側に逃がす案を可視化した。
色は経路識別用で、VDD/GND/DATAの線色ではない。線の端にプラグ実形状はまだ無い。
自由端の給電位置は仮であり、E148実位置ではない。

| 経路 | 保存姿勢での中心線長 mm | 部品包絡交差組数 | ケーブル交差 |
|---|---:|---:|---:|
| C0 給電位置案 → ベース | 151.0 | 3 | 0 |
| C1 ベース → 肩 | 185.8 | 6 | 0 |
| C2 肩 → 肘 | 292.6 | 6 | 0 |
| C3 肘 → 延長 | 193.2 | 5 | 0 |
| C4 延長 → 手首 | 291.2 | 5 | 0 |
| C5 手首 → グリッパー | 439.5 | 9 | C4と1組 |

長さは切断長や推奨購入長ではない。端末処理、固定点、可動たるみを含まない。
6経路とも設計上の最小曲げ半径15 mmを満たすが、干渉解消・実ケーブル仕様確認は別条件。
毎ポート付近に繰り返すケースとの交差は丸束近似やプラグ位置の精査が必要であり、
現物が同じ量だけ干渉すると断定しない。一方、台座・リンク・別モーター・ケーブルとの
交差も残っている。ケース全体を除外して見かけ上合格にはしない。
ベース下側へ回した経路は卓上クリアランスが未成立の可能性があり、取付面を含めて再設計する。

### 電源と信号は別に設計する

XL430は6.5～12.0 V、推奨11.1 V。TTL 3ピンは1=GND、2=VDD、3=DATA。
12 V時のストール電流は1台1.4 Aなので6台の単純合計は8.4 Aだが、これは
連続動作時の実電流を意味しない。
出典: [ROBOTIS XL430 e-Manual](https://emanual.robotis.com/docs/en/dxl/x/xl430-w250/)。

EHコネクタの定格はAWG22条件で3 A。よって全台の電流を先頭の1コネクタへ通す配線を
「12 V統一だから問題なし」とは判断しない。
出典: [JST EH仕様書](https://www.jst-mfg.com/product/pdf/eng/eEH.pdf)。

必要なのは、実負荷の電流見積りと測定、分岐ごとの配線・接点定格、電圧降下、保護の設計。
TTLの接続順と電源の供給経路を区別する。複数箇所への給電だけでは、VDDを接続した
3芯ケーブル間の回り込みや保護協調は解決しない。回路図と無通電の導通確認が必要。
E148の電流定格、配線長、実端子・圧着条件は未確認。任意のヒューズ値を指定しない。
ROBOTISの21 AWG表記とJSTの適用線範囲も自作圧着前に照合し、端子の適合を推測しない。
