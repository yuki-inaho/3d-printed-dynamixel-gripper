# PG2 R5 — 印刷・部品表・組立作業書

対象は背面縦置きのDYNAMIXEL XL430-W250を1台使う平行2爪です。案内棒、直動軸受、金属カラーは使いません。ケース付属の出力部、通常のねじ・ナット・座金は使用します。Mini Maxの配置を参考にした新設計で、元の寸法を複製したものではありません。

## 1. 基準と使用範囲

Xが左右、Yが枠の上下、Zが爪の突出方向です。サーボの長辺46.5 mmはY、出力軸はZ。出力部の取付面をZ=0とし、サーボケースは背面側にあります。本体外形は136×84×75 mm（サーボ・出力部を含み、カメラなし）。金属部品を除く本体は6種類・9個の印刷部品です。

クランク半径15 mm、リンクの両穴中心距離36 mm、運転用の機構角30〜140°。印刷爪の公称内幅は約0.8〜50.81 mm、片爪の移動量は約25.01 mmです。機構角は「中央クランクの連結穴を結ぶ線」の角度であり、サーボの絶対指令角ではありません。サーボと機構の角度差を測定してから使用します。

枠の開側ストッパーへ触れる計算角は約23.88°、閉側は約142.71°です。使用端での寸法余裕は開側約1.00 mm、閉側約0.29 mm。これは印刷誤差で変化するため、実機の端点を必ず再設定してください。ストッパーは誤動作時の当たり面で、駆動したまま押し付ける場所ではありません。

## 4. サーボを傷めないための寸法確認

ケース側面はメーカー図のPHS M2.6×5 TAPを基準にしました。座面からケースまで2.25 mmなので、ケースへの侵入は2.75 mmです。メーカーは側面穴の使用深さを最大4 mmとし、繰返しの使用によるねじ山損傷も注意しています。本体の分解や、ケースのM2.5通しねじの抜き替えは行いません。

中央回転板はM2ねじの座面を出力部取付面から3.0 mm前へ置き、M2×6による侵入を3.0 mmとしました。メーカーの注意図は「1.5 mm板にM2×5」を示し、同じ板厚でM2×6を使うと長過ぎるとしています。本案のM2×6は板厚の異なる専用座面と組み合わせる指定で、薄い板へ流用する指定ではありません。座面を削った場合、ねじ長も再計算が必要です。

側壁とケースの片側0.25 mmは組付けの逃げです。隙間を潰すために過大な力でねじを締めたり、ケースを変形させたりしないでください。実物の嵌合と締結保持は未試験です。

参照したモーター形状は、添付の `arm.step` 内 `XL-430_new v1:1` を取り出したものです。公開仕様表・メーカー取付図と照合しました。今回WebからメーカーのSTEP/PDFを直接取得したと主張するものではありません。取付穴の下穴径はCAD測定値で、そこからねじ規格を勝手に推測せず、メーカー取付図を優先しています。

## 5. 造形と隙間調整

試作の初期設定は、PETG、0.4 mmノズル、積層0.2 mm、外周4〜5周を想定しています。充填量と関節肩部・爪根元の局所設定は試作条件で、強度の認証値ではありません。スライサーで寸法を自動拡大縮小しないでください。STLの単位はmmです。

全STLは指定した印刷姿勢で床面Z=0に移動済みです。本体枠は背面、押さえは平らな前面、リンクは平面、中央回転板は取付面を床へ向けています。背面取付部はフランジ面を床にします。ナット穴の小さな橋、横穴の上面はスライサーで確認してください。

**爪は側面を床にし、根元の非摺動端面へ局所サポートを付けてください。** 窓付き爪を完全なサポート不要と扱ってはいけません。案内として使うY/Z方向の平面と関節肩部は、支えを除去する面にしない設定を採用しています。追加カメラ台にも、外側の腕や取付座の下で局所サポートが必要になる場合があります。スライサーで空中から始まる箇所を確認し、外観画像だけで印刷開始しないでください。

最初に09と10を印刷します。矩形試験片の厚さは4.2 mm、窓の高さは4.7 / 4.9 / 5.1 mmです。差の0.5 / 0.7 / 0.9 mmは**両面合計の隙間**です。標準では、案内後面0.3 mm、押さえ側0.4 mmを割り当てています。試験片の横方向総隙間は0.8 mmで、本体の上下逃げ0.2＋0.6 mmに対応させています。爪の補強部と押さえの内端は1.0 mm離し、最も上へ寄っても0.4 mm残します。抜け止めのかかりは標準3.0 mm、上下の遊びを考慮した最小値2.4 mmです。

丸穴6.2 / 6.4 / 6.6 mmは、金属棒用ではなく、直径6 mmの印刷した関節肩部の確認用です。本体リンクの穴は標準6.4 mm。肩部はZ=9〜13.5、リンクはZ=9.3〜13.3で、後側0.3 mm、座金側0.2 mmを見込んでいます。肩部が潰れたり、座金がリンクへ当たって回らなくなるものは不合格です。

試し刷りは本体の長い枠の反りや摩擦を再現しません。本体でもリンク未接続の状態で、左右の爪が手で端から端まで引っ掛からずに滑ることを確認します。動きが渋ければ、選択部品・造形条件・平面仕上げを見直し、モーター出力を増やして押し切らないでください。サーボの歯車を無理に手で逆駆動して検査する手順ではありません。

## 6. 組立順

1. 印刷品のバリと支えを除去し、試験片で隙間と関節径を選びます。印刷部品だけのねじ通し穴を必要に応じて仕上げます。サーボケースの穴をドリルで拡大しません。
2. 背面取付部にM3ナット4個を入れ、電源を切ったXL430を差し込みます。指定の側面タップねじ4本を左右から取り付けます。既存ケースねじ・中心ねじは外しません。
3. 本体枠のナット座へ押さえ用ナット8個を入れます。カメラを使う場合は上側中央の追加2個もこの時点で入れます。本体枠を背面取付部へM3皿ねじ4本で固定します。皿頭が摺動面より突出しないことを確認します。
4. リンクと爪をまだ取り付けない状態でサーボの位置を確認し、出力部へ回転板を指定M2ねじ4本で固定します。回転板の関節ナット2個も先に入れます。指令値と機構角の対応を測定し、低出力・低速度で30〜140°の範囲を設定します。ここが未確認のままリンクを接続しません。電源を切って次へ進みます。
5. 爪の裏側へM3ナット各1個を入れ、左右の爪を本体前面から載せます。同じ爪を片側だけZ軸まわりに180°回して使います。上下の押さえをM3×12各4本で固定し、リンク未接続で軽い摺動を確認します。押さえねじを緩めて隙間を作る方法は使いません。
6. 回転板と左右爪へリンクを取り付けます。肩の外側にリンク、肩の端面に座金、上からボルトの順です。回転板側はM3×12、爪側はM3×10。座金が肩に着座してもリンクが自由に回ることを確認し、強く締めて印刷肩を潰しません。締付トルク・緩み止め方式は実機での承認が必要です。
7. カメラを使う場合は、**最初に取付板08だけへM2ナットを入れ、基板をM2ねじ4本で固定します。この段階では台07を付けません。** 次に板の前側へM3ナットを入れ、台07を合わせ、M3×12を後ろから締めます。最後に台全体を上側中央のM3×16の2本で本体へ固定します。台が付いたままでは下側の基板ねじ2本への工具が台と干渉します。基板ねじの再締結・交換時は、まず後側のM3×12を外して取付板を台から取り外してください。
8. ねじ先端の突出、ケースへの侵入、皿頭、関節遊び、支え除去面、ケーブルの引張りを確認します。カメラやケーブルを後付けした場合は、同じ空間検査がそのまま適用できると考えないでください。

## 7. 通電と実機の受入

XL430-W250のメーカー仕様は6.5〜12.0 V、推奨11.1 Vです。前案のXL330用5 Vという説明を流用しないでください。接続極性を確認し、通電したままケーブルを抜き差ししません。動作域へ指を入れず、電源をすぐ遮断できる状態で初回動作を行います。

初回は無負荷、低速度、低いPWM上限から始め、機構が停止したまま押し続けないようにします。PWM上限・Present Loadを校正済みの把持力と見なしてはいけません。本案は停止トルクを使って定格把持力を決めておらず、対象物の許容押圧や連続運転荷重は未確定です。

後付けパッドは有効開口と必要な停止角を変えます。パッドを追加したまま元の閉じ端へ押し付け続けないでください。

実機側で未完の受入項目は別紙 `PHYSICAL_ACCEPTANCE_ja.md` に残しています。本データだけで、製作成功率、把持力、繰返し精度、耐久寿命を保証しません。

## 8. カメラC3の扱い

32×32×1.6 mm基板、28×28 mmの穴ピッチを仮定した追加品です。短い台で光学中心を上桟の前へ出し、65°下向きに置きます。カメラなしでも本体は完成します。実カメラの機種、最短撮影距離、画角、ピント、レンズの歪み、コネクタと配線は未指定です。

C3の検査は理想画角とCADの視線です。実画像や実レンズの検証ではなく、爪全体・把持物全体の可視を保証するものでもありません。別のカメラを使う場合は08の取付板と光学検査を変更します。
