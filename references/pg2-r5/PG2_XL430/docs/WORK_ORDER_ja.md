# PG2 / XL430-W250 / 作業書・要求凍結

開始日: 2026-09-22。対象: PG1 R7の改訂ではなく、要求配置を復元する独立した試作CAD。元ファイルは変更しない。

## 先に行う辛口レビュー

PG1 R7は機構原理だけを拾い、参照画像の構成を保存しなかった。サーボ出力軸と爪の突出方向が直交し、細長い指と150 mmの金属丸棒案内へ変更した。これは依頼者が求めた「この画像のようなもの」の実装ではない。既知の330系を暫定採用し、指定モーターの確定を受入条件に入れなかった。締結部品の追加と干渉修正を繰り返したが、そもそも要求違反なので検査件数が多くても納品の根拠にならない。印刷用メッシュの健全性・CAD干渉・組立成立・現物性能は別の証明である。

## 変更してはいけない条件

R01: 単一サーボは DYNAMIXEL XL430-W250。XL330、AX-12その他への置換禁止。
R02: X=左右開閉、Y=枠の上下、Z=前方(爪の突出方向)。出力軸は+Z、モーターの46.5 mm長辺はY。見せ方だけの90°回転は不合格。
R03: モーターは枠の背面、回転板と2本の連接棒は枠の前面。直動する短い窓付きの爪2枚。閉じても把持中心X=0。
R04: 金属ガイド軸、リニア軸受、金属関節カラーを追加しない。案内は印刷した角形の滑り面。関節の肩部も印刷形状。標準ねじ・ナット・座金、サーボの既製出力部は使用する。
R05: 印刷部品を別体で印刷して組立。印刷一体可動、強い圧入、印刷スプラインでの軸直結は禁止。
R06: 隙間は試し刷りで選べる。隙間をゼロにしてCADを見栄えよくすることは禁止。
R07: 前面・側面・斜視で参照と構造を比較する。CGの見栄えだけでは承認しない。
R08: カメラは着脱式の追加品。短い台で取り付け、グリッパーの基本配置を崩さない。実カメラ型番は未指定。

## 今回完了させるDoD(デジタル試作)

D01 要求R01〜R08とCAD/部品表の追跡表、および禁止例を弾く自動検査。
D02 添付のXL430_new CADからケース外形・出力面・取付孔を実測して基準化。メーカー公開仕様と相互確認。モーター自体の内部重複は別扱い。
D03 左右対称運動・穴間距離・公称開口・使用角範囲を計算し、死点を避ける。
D04 ねじ頭・ナット・座金・印刷肩部をモデル化し、使用角範囲を離散走査。許容するねじ/下穴の重複は対ごとに明記。例外の追加でエラーを隠さない。
D05 案内の捕捉量、保持面の厚さ、閉止/開放側の余裕、組立/工具方向を確認。
D06 全出力STEPは再読込・有効形状確認。全STLは閉じた正体積・法線整合・非多様体辺なし。
D07 印刷姿勢・部品数量・締結長・隙間の意味・組立順・通電前検査を文書化。失敗と修正を履歴に残す。
D08 最終CADから斜視・正面・側面・分解・開閉図を生成し、作業書・結果・再生成源を同梱。

## DoDに含めないが、隠さない現物未検証

印刷品の摩擦/反り/摩耗、締結強度、サーボケースのねじ山、把持力、繰返し精度、持上げ質量、連続運転温度、実配線、実カメラ、ロボット全腕への互換性と全関節衝突。これらを「達成済み」とはしない。安全な量産/実機承認のDoDは別紙で未完のまま保持する。

## 作業記録

- 01: 前案ソースで output=+Z / fingertips=+Y / rod=6x150 を確認。要求R02/R04の不一致として記録。
- 02: 添付 low_cost_robot の arm.step 内 XL-430_new v1:1 を35要素で抽出。330系データは一切転用しない。
- 03: メーカー資料でケース側面はセルフタップ穴、侵入深さ上限4 mmと確認。通常M2.5機械ねじの前提を棄却。PHS M2.6x5 TAPの図示仕様に合わせる。
- 04: R1の実CADを正面・側面・斜視で描画。サーボ長辺Y、出力軸Z、爪突出Zを確認。6種9個の印刷本体とし、長い金属丸棒は廃止。外形は写真の寸法コピーではなくXL430に合わせた新規寸法。
- 05: R1初回走査は30°/45°で不許可干渉0件まで進んだが、処理時間上限で中断。全域合格とは扱わず、同一剛体内の相対位置が不変の対だけ初回検査にまとめる実行方法へ変更。
- 06: 爪の側面印刷では根元に空中で始まる箇所があると目視で判定。サポート不要の宣言を禁止し、非摺動面の根元だけ支えを付ける印刷姿勢を指定する。摩擦面は上向き/垂直とし、支えの除去面と分離する。
- 07: R1の30〜150°・15°刻み9姿勢は体積干渉0。ただし把持点の前出しに対して摺動支持長24 mmは短いと判断。CAD干渉0をそのまま採用理由にせず、R2で爪先Z45→36 mm、支持長24→28 mmへ修正。枠幅132→136 mm。窓の角に半径2 mmを追加。
- 08: R1のクランク関節M3x10ではナットからの突出が小さいため、クランク側だけM3x12に変更。爪側はM3x10を維持。メーカー側取付ねじの侵入長は別計算し、長くして解決しない。
- 09: R2本体13姿勢（10°刻み）の干渉0。別体カメラ台の初期形状は有効形状でも3ソリッドに分離しており不合格。基板面で支持腕が切断されていたため、腕を基板外側へ移し、後側の取付座へ回り込ませて接続。isValidだけでなくソリッド数=1を必須とする。
- 10: カメラ台を1ソリッドへ修正後、カメラ込み5姿勢の不許可干渉0。カメラは本体へ付ける前に組み立てる順序を固定し、基板面への工具が本体枠を貫通するような手順は禁止する。
- 11: 使用域外を追加点検すると、150°より閉じた側で爪が接触する前にリンク根元の間隔が小さくなる。停止を機構の内部衝突へ任せないため、R3で閉じ指令上限を140°へ戻し、上下ガイドの中央に印刷ストッパーを追加。公称開口約0.8〜50.8 mm。閉側余裕約0.29 mm、開側約1.00 mmを持ち、現物ではこの余裕を原点校正で再確認する。
- 12: R3は構築中モデルの111姿勢・STL12点・STEP形状妥当性で合格。ただし保存STEPの部品間検査で、枠と右下のナットにナット全体体積45.91 mm³の交差判定。形状クラス判定では同ポケット内5点がすべて外部で、構築時とも食い違う。原因を確定せず、数値不整合が疑われるものとして記録。合格にはしない。
- 13: R4で本体枠の繰返しナット座を6.8×5.9 mmの角ポケットに変更。5.9 mmの二面で二面幅5.5 mmナットを保持する。相手形状との余裕を残し、許容干渉の追加やしきい値緩和では処理しない。保存後の組合せ検査を受入の必須項目へ固定する。
- 14: 追加カメラC1の投影角だけの検査では、上桟による遮蔽を排除できない。光学中心から爪への線を追うと上桟を横切ると判断し、C1を視認合格にはしない。C2ではレンズを上桟の前側へ出し、65°下向きの短い台へ変更。外形だけでなく視線も検査する。基板取付板のM3ねじは後ろ側から締め、工具が前側の台を通過しない構成に修正。
- 15: R4本体の幾何形状はC2変更では不変。R4の111姿勢試験は本体同士の検証として保存し、C2と本体の全組合せを同じ111姿勢で追加検証する。旧カメラの試験を新カメラの試験と呼び替えない。
- 16: C2の視線54本は通るが、仮レンズ筐体と押さえ／台の体積干渉が2対で残ったため不合格。光線が通ることとカメラ本体が取り付くことを別の条件として扱う。C3で基板基準点をY56/Z20へ移し、支持腕を接続し直す。65°は維持し、レンズ筐体も含めて再走査する。
- 17: C3はレンズ筐体の干渉0、111姿勢の追加部品検査合格、3姿勢54本の視線合格。
- 18: 受入前にガイドの体積交差だけでなく最短距離を実測すると、R4の押さえ内端と爪の補強部が公称Y32で接触していた（距離0）。体積干渉0でも低い造形精度には不適切なので不合格。R5で押さえの内端をY33へ退け、公称1 mmの逃げを追加。爪が上下に寄った状態も考え、逃げ最小0.4 mm、抜け止めのかかり最小2.4 mmを残す。
- 19: 実形状のガイド最短距離>0.15 mmを自動受入条件に追加。正しいパラメータ表示のまま押さえ形状だけをずらして隙間を0にする負例も追加（計12例）。R5は111姿勢を全組合せで再走査し、R4の結果で代用しない。

- 20: C3の下側基板ねじ2本への工具軸が台に各0.00788 mm³干渉したため、工具検査は不合格。カメラを本体から外すだけでは解決しないことを確認。形状の重複を例外にせず、基板を独立した取付板へ固定→台へ板を後側から固定→本体へ取付、の作業順に変更。基板ねじの整備には板を台から取り外すことを明記し、検査もその組立段階の実部品集合で再実行する。本体・カメラの形状変更はない。

- 21: R5＋C3の全111姿勢が、不許可体積干渉0・ガイド最短距離条件の双方で合格。最小値は枠0.20 mm、上下押さえ0.40 mm。保存組立STEP4点、個別部品を含むSTEP16点、STL12点、工程別工具軸32件、運動計算1101点、負例12種類も合格。負例は指定した違反を検出するもので、あらゆる誤設計を検出する保証ではない。
- 22: 印刷姿勢一覧の初期画像は上方向が組立用Yのままで、床面Zの理解を妨げると判断。Z上向きの個別図へ再描画し、寸法・数量・爪の局所支え注意を添えた。STEP/STLの形状は変更なし。最終斜視・側面・閉正面・分解・カメラ・印刷姿勢を目視確認。
- 23: 参照STEPの一部の名前にWindowsで使えない > 記号が残っていたため、安全なファイル名へ変更。変更前後のSHA-256が同一で、STEPの中身を変更していないことを記録。元の要素名・元パスは対応表に保持。
- 24: 凍結したデジタル試作DoD D01〜D08の最終集約を通過。現物受入はすべて未実施のまま別紙に維持。型番、姿勢、材料、単一ソリッド、ガイド隙間、保存後再検査、工程別工具検査を公開停止条件とし、確認していない全腕互換は主張しない。
