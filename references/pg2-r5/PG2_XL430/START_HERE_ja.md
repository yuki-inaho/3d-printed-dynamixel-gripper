# PG2 R5 — XL430-W250縦置き・印刷ガイドの平行2爪

このフォルダは、Mini Maxの参照画像の配置に戻した独立した試作CADです。前案PG1 R7の寝かせたXL330・金属丸棒構成は採用していません。参照の寸法コピーではなく、XL430-W250に合わせた新規設計です。

## 最初に見るファイル

- `PG2_design_review_ja.html`: 画像・開閉表示・要求追跡・最終検査・作業書をまとめた日本語レビュー。画像を内蔵し、単独で閲覧できます。
- `CAD/PG2_open.step` / `PG2_mid.step` / `PG2_closed.step`: モーターと外部締結部品を含む組立形状。
- `STL/`: 印刷用の唯一の最終出力場所。単位mm、指定姿勢で床面Z=0。
- `docs/ASSEMBLY_AND_PRINT_ja.md`: 正確な数量、ねじ長、試し刷り、組立順。
- `docs/WORK_ORDER_ja.md`: 前案の辛口レビュー、凍結要求、DoD、失敗と修正履歴。
- `docs/PHYSICAL_ACCEPTANCE_ja.md`: 現物の未実施検査。未検証を合格へ読み替えません。
- `source/README_ja.md`: 再生成と検査の実行方法。

## 基本構成

単一DYNAMIXEL XL430-W250を背面に縦置き。出力軸と爪の突出方向は同じです。前面の中央回転板とリンク2本で、2枚の爪を左右対称に直動させます。上下の角形案内面・押さえ・関節肩部を印刷します。金属ガイド棒、直動軸受、金属カラーはありません。ただし標準ねじ・ナット・座金と、サーボの既製出力部は使います。

本体は6種類9個の印刷品。カメラは追加2個の任意部品です。本体外形136×84×75 mm、硬い爪同士の公称開口0.8〜50.81 mm、運転用の機構相対角30〜140°。角度をそのままサーボへ送らず、原点と機構角の対応を確認します。

## 印刷前

最初に `09_fit_gauge.stl` と `10_fit_tongue.stl` を各1個印刷します。隙間0.5/0.7/0.9 mmは両面合計です。押さえは採用した隙間のものを上下各1個、計2個印刷します。標準9個の数量は作業書の表に従います。12個のSTLファイルを全部1個ずつ印刷する方法ではありません。

爪03は側面印刷で、根元の非摺動面へ局所サポートが必要です。完全サポート不要・一体可動印刷とは扱っていません。追加カメラの基板は、台07を付ける前に取付板08へ固定してください。

## 承認範囲

最終判定は `reports/RELEASE_DOD.json` の `digital_prototype_DoD_pass` で確認します。これはデジタル試作の検査で、印刷・組立・摩擦・強度・把持力・耐久・実カメラ・実機通電の承認ではありません。全腕への取付互換・全関節干渉も未承認です。前案のアーム取付STEPを流用しません。

本体の111姿勢走査は標準総隙間0.7 mm品を対象にしています。0.5/0.9 mm選択品は個別形状の出力健全性を検査していますが、同じ回数の実形状走査をしたとは主張しません。

`reports/iterations/` は不合格・旧版の記録です。ここにある旧STEPは製作用ではありません。`reference/` のモーターは添付CAD由来の既製品参考形状であり、印刷しません。

ファイルの同一性は `MANIFEST.sha256` に記録しています。`python source/release_gate.py --verify-manifest` で確認できます。
