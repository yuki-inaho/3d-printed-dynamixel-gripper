# 横開きジョー＋交換式手首カメラマウント — 2026-09-22

**状態：幾何検証用プロトタイプ。製作・実機投入の承認ではありません。**

既存の low_cost_robot の指・サーボ受けを作り直さず、手首取付部でグリッパモジュール全体を **90°クロック**し、カメラ画像の左右方向に指が開くように配置します。新しい4 mm厚の取付フランジとカメラ支持部を追加し、元の固定指・可動指・サーボ形状はそのまま使います。

SO-ARM100/101 Parallel Gripper の「手首カメラ＋交換式ホルダー」を参照していますが、同リポジトリのラック／平行移動機構やメッシュは移植していません。**本案は従来どおり固定指1本＋回転する可動指1本**です。左右対称に両指が平行移動するグリッパではありません。

## 1. 基準と変更範囲

基準は、このブランチにある `follower_geometry_revision` の **XL430×2＋XL330系×4の混在サーボ版**です。`hardware/follower/step` のハッシュを確認して既存の局所補正を再生成し、その上に今回の配置変更を加えます。全XL430版の未解決干渉や取り付け判定は引き継ぎません。

| 対象 | 扱い |
|---|---|
| `hardware/` の元ファイル | 一切変更しない |
| 基準アセンブリの161末端要素の形状 | 全て既存B-repを直接再利用 |
| 手首より上流の部品配置 | 混在版基準と同一 |
| `/gripper v9:1/` 以下の配置 | 手首4穴中心まわりに90°回転、軸方向へ4 mm移動 |
| 可動指・グリッパのホーン／アイドラ | 検証用開き角0〜50°。軸と相対取り付け形状は維持 |
| 新規形状 | 支持ブリッジ、UVC28キャリア、4 mmスペーサーの3点のみ |
| カメラ基板・レンズ・背面部品 | 型番未定の仮定外形。購入部品の正規CADではない |

原形保存は `intent/design_intent.yaml` の変更マスクに従います。汎用 `src/cadre/`、元のハードウェア、既存ファームウェア／URDFは変更していません。

## 2. カメラ仕様と座標

カメラ未指定のため、参照先 `docs/assembly-guide.md` Step 9 に記載された **28×28 mmの取付穴ピッチ**を採用しました。以下の寸法はこの試作の仮定であり、特定製品の適合保証ではありません。

| 項目 | 設計値・仮定 |
|---|---|
| 基板取付穴 | 28×28 mm、4穴、通し穴Ø2.3 mm |
| 基板外形 | 32×32×1.6 mmの仮定 |
| レンズ外形 | Ø16×8 mmの仮定 |
| キャリア | 外周38 mm、開口24×24 mm、厚さ3 mm、下部取付タブ付き |
| 基板スペーサー | 外周36 mm、開口24×24 mm、厚さ4 mm |
| キャリアと支持部の接続 | 24 mmピッチ、M3想定2本、背面六角ナット溝 |
| カメラ俯角 | 手の前方から下へ40° |
| 仮定画角 | 水平60°・垂直45°。実測・校正していない |

H座標は元の固定指のローカル座標です。+Xが画像右、+Yが指先方向、+Zがヒンジ軸／カメラ側です。キャリア基準は `[12,-40,78] mm`、光学中心の仮定は `[12,-27.283662,67.329726] mm` です。光学座標は x右・y下・z前です。計算した変換行列は出力の `kinematics.json` に含めます。

**RealSense D405等への互換性は未実装・未確認です。** 実機の型番が決まったら、2本のM3接続より先のキャリアを交換する設計です。単に穴ピッチだけ一致しても、レンズ位置・基板部品高さ・USBコネクタ・画角・焦点が合うとは限りません。

## 4. 検証の意味と限界

**原形保存**：既存161要素は同じB-repを直接利用し、STEP再読込後も面数・ソリッド数・頂点の双方向距離・体積・面積・外接箱を照合します。既存の供給元CADの再保存には微小な質量特性差が出るため、独立の無変更対照STEPも保存します。直接比較の体積・面積差を0.01%以内に制限し、許可された配置変更を戻した候補と対照をより厳しく照合します。対照との差を記録せずに閾値だけを緩める方法は採っていません。元の固定指・可動指を簡略な形に作り直す方法は採っていません。

**組立干渉**：閉じ・50°開きの保存済み全腕STEPで、外接箱の候補抽出後に正確なB-rep交差体積を計算します。同じ供給元サーボ内部のCAD重複は別集計し、腕部品どうしの干渉と混ぜません。計算例外は失敗です。体積閾値は1e-4 mm³、外接箱侵入閾値は1e-5 mmです。接触面やネジの締結可否は別問題です。

**動作**：他の関節を基準姿勢に固定し、指の開き0〜50°を5°刻みで調べます。さらに、回転する可動指と新設マウント／仮定カメラについてだけは保守的外接箱による連続区間の分離下界を計算します。全腕の全関節動作、たわみ、配線の掃引は対象外です。

**視認性**：保存済み全腕STEPを三角形に分割し、閉じ姿勢で面の重心がH座標Y≧25 mmにある指先側の面群を対象にします。各指の面上サンプルに対して、カメラから最初に当たる三角形を調べ、自己遮蔽も含めます。0〜50°を1°刻みで評価します。対象面群の頂点が仮定画角内にあることと、各指に8点以上の可視面サンプルがあることを要求します。これは実カメラの解像度、指全体の根元までの可視性、把持物による遮蔽、反射、焦点、露出の保証ではありません。

**STEP/STL**：新規3部品のソリッド数、B-rep妥当性、STLの閉鎖性・向き・正体積、体積差、外接箱差を確認します。STLはCAD座標姿勢です。造形姿勢・サポート・積層方向・材料・スライス条件の承認は行っていません。G-codeは含めません。

## 5. 組立案と締結の未確認事項

電源を切り、把持物を外し、腕とグリッパを支持した状態で作業してください。初回の動作確認は人や物を挟まないように行い、無理に可動端へ押し込まないでください。

1. 元のグリッパ取付状態とケーブルの向きを記録し、必要な指／サーボを取り外して取付4穴の工具経路を空けます。完成姿勢で穴が同軸でも、サーボ装着後に工具が入るとは限りません。
2. 手首の既存4穴にブリッジの4 mmフランジを挟み、グリッパを90°組み替えます。元の固定指は形状を変更しません。
3. ブリッジと固定指の締結後にグリッパサーボ／可動指を戻します。元のスプライン位相を記録し、制御上の原点と実際の閉じ位置を確認します。
4. キャリア背面にM2想定ナット4個、ブリッジ背面にM3想定ナット2個を先に入れます。基板・4 mmスペーサー・キャリアを組み、次にキャリアをブリッジに取り付けます。
5. USB配線を上部の結束バンド用窓に固定し、接続部に荷重をかけないサービスループを取ります。実コネクタの向き・最小曲げ半径・関節全域の余長は現物で検証します。

| 締結箇所 | 設計で分かること | 製作前に確定すること |
|---|---|---|
| 手首4箇所 | 既存の半径6 mmの4穴パターン、静的部品Ø2.3、ホーンCAD小径穴Ø1.6、追加厚4 mm | 実ねじ規格、ホーン有効ねじ深さ、先端底付き、座面、締付トルク。元のねじに単純に4 mm加えた長さを無検証で使わない |
| カメラ基板4箇所 | Ø2.3通し、28×28、M2想定六角ナット溝AF4.25／深さ1.8 | 実基板厚・部品高さ・ワッシャ・ねじ長。仮のスタックではM2×10が候補だが未確定 |
| キャリア2箇所 | Ø3.2通し、24 mmピッチ、M3想定溝AF5.7／深さ2.5 | ナットと頭の形、工具経路、実積層厚、締結。仮のスタックではM3×8が候補だが未確定 |

ホーンのCAD小径穴からねじ規格・許容ねじ込み量を断定していません。六角穴の造形収縮や保持力も未確認です。支持部の強度計算・実荷重試験・疲労試験は未実施です。

## 6. 制御・カメラ校正

既存ファームウェア、URDF、可動端コマンドは変更していません。取付の90°クロックと軸方向4 mm追加により、同じ関節角でも工具姿勢・TCPが変わります。実機では工具座標、カメラ外部パラメータ、関節原点／可動範囲、干渉モデルを更新・校正してください。`kinematics.json` はこのCAD基準姿勢の値であり、実機へそのまま適用する校正結果ではありません。
