## 変更したもの

固定指・可動指・サーボ形状を保存し、既存手首の4穴パターンを利用してグリッパ全体を90°組み替えました。4 mm厚のフランジを追加し、工具長は同じ軸方向に4 mm増えます。カメラは指の上方・後方に置き、画像右方向を指の開く方向に合わせています。新規部品は `wrist_camera_bridge`、`uvc28_camera_carrier`、`uvc28_pcb_spacer_4mm` の3点です。

本案は **固定指＋回転指** のままです。SO-ARM100/101 の平行ジョー機構は移植していません。参照したのは交換式のカメラ支持構成と28×28 mmの取付穴ピッチです。カメラ自体は32×32 mm基板、Ø16×8 mmレンズ等の仮定外形です。

基準は `follower_geometry_revision` の **混在サーボ版（XL430×2＋XL330系×4）**。全XL430版の未解決干渉を承認したり、本案の結果を全XL430版へ流用したりしていません。

## 検証結果

| 項目 | 結果 | 範囲 |
|---|---|---|
| 原形保存 | 既存161末端要素のB-repを直接再利用、上流配置差ゼロ | 混在版基準に対して |
| 保存済みSTEP | 167末端要素／123ソリッド | 新規部品3＋仮定カメラ外形3を含む |
| 閉じ姿勢の全腕干渉 | 外部干渉0、374候補すべて計算成功 | 保存済みSTEPを再読込 |
| 50°開きの全腕干渉 | 外部干渉0、374候補すべて計算成功 | 同上 |
| サーボ内部の供給元CAD重複 | 両姿勢とも116ペア、別集計 | 「干渉ゼロ」に含めて消していない |
| 指の動作 | 0〜50°・5°刻み、11姿勢すべて外部干渉0 | 他の関節は固定。各姿勢16候補を計算 |
| 新設部と可動指 | 連続回転区間で支持部との分離下界 **1.729 mm** | 新設部／仮定カメラに対する保守的外接箱判定のみ |
| 両指の視認性 | 0〜50°・1°刻み、51姿勢すべて合格 | 水平60°・垂直45°の仮定、自己遮蔽を含む |
| 新規3部品 | 妥当な単一ソリッドSTEP、閉じた正体積STL | 造形条件・強度・現物嵌合の承認ではない |
| 新規自動テスト | **42 passed** | 不正設定・重複穴・遮蔽・干渉の負例を含む |
| 既存混在版の回帰テスト | **46 passed** | `follower_geometry_revision/source/test_revision.py` |
| 製作パッケージ | 実行時に再検証し、終了コード2で拒否 | 実機の未確認事項をフラグだけで承認できない |

視認対象は、閉じ姿勢で面重心が元の固定指座標Y≧25 mmにある指先側の三角形群です。51姿勢の最低可視サンプル数は固定指96点・可動指31点。対象面群の頂点は仮定画角内です。指の根元全体や把持物の背後まで見えることを保証していません。画像の根元が切れることはプレビューでも示しています。

既存CADのSTEP再保存だけで生じる微小差は、無変更の対照STEP `CAD/reference/mixed_baseline_noop.step` を別に生成して照合しています。直接保存前との最大体積相対差は約0.002946%、対照STEPと配置を戻して比較した最大体積差は約3.64e-12 mm³です。元との頂点距離最大は約4.89e-11 mm、外接箱差最大は約1.01e-7 mmです。微小な保存差を「設計による形状変更」と混同せず、元形状・対照・配置例外を分けて記録しています。

新規3部品の合計ソリッド体積は **10.850 cm³** です。材料や充填率を決めていないため、造形物の質量・剛性は算定していません。

## まだ承認していないもの

実カメラの型番・画角・焦点・基板部品高さ・USBコネクタ、手首ホーンのねじ規格と有効深さ、ねじ長・締結・工具アクセス、造形方向と材料強度、実配線および全関節掃引、実機の嵌合・校正は未確認です。特に **手首に4 mmを追加するため、既存のねじをそのまま流用できるとは限りません**。カメラ用のM2×10やキャリア用M3×8は仮スタック上の候補に留め、確定BOMにはしていません。

ファームウェアとURDFは変更していません。実機では工具座標・カメラ外部パラメータ・可動範囲を更新してください。今回の90°は取付の組み替えで、ソフトウェアの関節指令に無条件で90°を加える指示ではありません。
