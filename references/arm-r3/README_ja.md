# 全XL430 CAD干渉修正 R3

本版は元の54組の外部干渉を残した剛体置換版ではありません。台座・旋回部を流用し、肩の上流形状を保護しながら、旧XL330取付部と下流4部品を再設計したCADです。
R1/R2は画像のみ参照可能で、同版のソース・CADをそのまま引き継いだとは扱いません。

## 最初に開くもの
- `REVIEW_ja.html`：画像付き検証結果。
- `WORKDOC_ja.md`：今回の対象範囲と完了条件。
- `CAD/arm_XL430_R3.step`：217末端要素の組立。
- `CAD/parts/`：7部品のSTEPとSTL。座標・単位はmm、組立座標を保持します。
- `reports/summary.json`：合否の適用範囲。`poses_rejected.csv`にNG姿勢を保持します。

## 再現
Python 3.13で確認しました。必要なパッケージは`requirements.txt`に実行版を記録しています。

```sh
python -m pip install -r requirements.txt
python source/build.py
python source/check.py
python source/validate_parts.py
python source/motion.py full
```

最後の広域検査は、既知の複合折返し36姿勢を含むため**終了コード2が正しい結果**です。エラーを無視して全域合格と表示してはいけません。
単独軸188姿勢、基準姿勢、複合グリッドの内訳はJSON/CSVを参照してください。

任意の指定姿勢を再判定する例：

```sh
python source/check_pose.py 0 0 -30 -30 0 25
```

角度順はJ1旋回、J2肩、J3肘、J4手首曲げ、J5手首旋回、J6把持です。単位は度です。基準は本CADの保存姿勢で、モーターのエンコーダ値と同一ではありません。

`check_pose.py`は角度範囲と`q3+q4 >= -90°`を入口条件として確認し、その後**実CADで全物理ユニット対を計算**します。この不等式を満たすだけでは合格になりません。追加の取付ねじ、配線、机面、工具、弾性変形は検査対象外です。

`python -m pytest -q tests`は検査記録・入口条件の回帰検査です。上記の実CAD再計算とは別です。

## 合否の意味
基準姿勢のB-rep体積干渉閾値は1e-4 mm³です。接する面だけの接触は干渉件数に含めません。同じ供給元モーター内部の168組の重なりは別集計し、外部干渉として隠していません。

5度刻みの単独軸検査は各々合格しましたが、各関節角を同時に自由に組み合わせる保証ではありません。有限姿勢での判定であり、その間の連続経路、全可動域、公差・強度・保持トルク・実機組立を承認していません。

STLは形状確認用です。部品の印刷姿勢・材料・温度・プリンター設定は未確定で、K1C用G-codeは含みません。旧版の部品と混用しないでください。

## 参照形状と変更
供給元モーターは、ユーザー提供STEP内の`XL-430_new v1:1`の35末端形状を剛体配置しています。モーターを切削・縮小したり、外部部品をモーターと融合したりしていません。
形状・穴の寸法根拠はこの参照CADです。第三者の市販品と実物が一致することは未検証です。

P01/P02は元B-repを剛体移動して再使用しています。P03の保護領域は変更マスク除去後の表面を両方向各3,000点で比較（最大0.04231 mm、判定閾値0.05 mm）。共面形状同士の差分演算で無効形状が出たため、その結果を「材料差分0」とは報告していません。詳細は`reports/parts.json`に記録しています。

モーター参照部品はケース単位の剛体として扱い、内部歯車やホーン等を独立して動かす機構検証はしていません。
