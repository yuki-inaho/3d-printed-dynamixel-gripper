PG3 グリッパ組み立てマニュアル

10手順／グリッパ単体1台分／2026-10-03／実物確認前のドラフト

低背型V2（爪+20 mm）のグリッパが対象です。カメラ、アーム、P05の取り付けは含めません。ID5のXL430-W250-T 1台で開閉します。対象CADのSHAは同梱の review-checks.json に記録しています。

実物写真との版照合（10/3追記）： 提供されたグリッパ写真は、細い接触板の旧C7が有力です。本書のV2とは爪・スライダ・パッドの形状が異なる可能性があります。写真の爪に本書の完成形状やパッド寸法をそのまま適用せず、爪板の前後長を照合してください（C7：12.1 mm、C9：28.0 mm、V2：48.0 mm、いずれも設計値）。C7からC9への改訂は爪2個とスライダ2個の交換です。照合概要は 実物写真との版照合 に記録しました。

現時点で実物組立を承認する手順書ではありません。 ケース固定ねじ、実ねじのかかり、締付トルク、印刷公差、ナットの保持方法が未確定です。工程2のケース固定は確認待ち。図はCADの取り付け位置を工程順に表示したもので、部品の挿入経路や実工具の操作を実証した写真ではありません。

P05の配線窓（10/3改善）： 保存V2の3×8 mmから、別候補では左右各5.5×10.2 mm・四隅R0.5 mmへ拡大しています。ねじ穴と実ケース座面は保持。直径1.9 mmの仮線に対するP05側の余裕は0.55→1.65 mmです。EHR-3公称筐体9.5×3.8 mmを縦向きに通す窓単体の検査は、モーター取り付け前の状態で最小0.35 mmの隙間があります。モーター装着後の直線コネクタアクセスは後カバーに当たるので合格ではありません。内部90度曲げ・後カバー側0.25 mmの仮経路、配線済みモーターの挿入・実ハーネス・印刷公差は未確認です。P05の内幅28.5 mmとケース公称幅の一致も組付け合格を意味しません。P05改善候補の詳細 を参照してください。本書のグリッパ部分は元V2と同形状です。

手順1／部品と向きを確認する

使うねじ：なし。

• 本体枠、押さえ2個、スライダ2個、爪2個、クランク、リンク2個、スペーサーを並べます。

• 左右の品名はCADのL/Rに合わせます。見ている方向で左右が変わるため、画像だけでL/Rを判断しません。

• 本書の正面図は爪側からモーターへ向かって見る図です。この視点では画面左がCADのR、画面右がCADのLです。斜視では奥行きも確認します。

• U/Dは部品名です。この固定版では PG3_cap_U が図の下、PG3_cap_D が図の上に配置されています。品名のUを画面の上と読み替えません。

• 爪の把持面を内側へ向けます。スライダの上下の延長シューは中央を向く配置です。

• 穴のつぶれ、摺動面の突起、割れを点検します。合わない穴をこのマニュアルの判断だけで拡大しません。

確認： V2の延長爪が左右1個ずつあり、ねじを長さ別に分けられていること。

手順2／本体枠とID5ケースの固定を確認する【確認待ち】

使用候補：B6＝ねじ径2.6 mm、頭込みCAD全長5 mm、2本。本体枠×1、ID5モーター×1。ナット・座金なし。

B6の長さ5 mmは皿頭を含むモデル全長です。実物に使うねじの規格・長さは確認待ちです。

枠を出力ホーン側に配置する設計です。CADでは PG3_case_tapper_-11 と PG3_case_tapper_11 の2本を使います。ただし、このM2.6皿タッピング全長5のモデルを、そのまま購入品や実ケースの前ぶたねじに置き換えてよいとは確認できていません。

ここは実物への取り付けを進める前の停止点です。 相手がケースの下穴か、既存ケースねじの交換位置かを実物と図面で特定し、ねじ種類・頭の座り・有効深さ・底付き・ケース締結の維持を確認します。前ぶたの元ねじは別資料ではFHS M2.5×10であり、B6を同じねじと扱いません。未確認のねじをねじ込まないでください。

以降の図と手順は、この固定が成立した場合の組立計画です。ケース固定が完了した記録を意味しません。

手順3／ホーンスペーサーとクランクを配置する

使用：B1＝ねじ径2 mm（M2）、長さ6 mm、4本。クランク×1、スペーサー×1。支点用N1×2を先に用意。座金なし。

ボルトの長さは6 mmです。頭の下面から先端までの長さで、頭は含みません。

• クランク側の左右支点ナット2個は、背面へアクセスできる段階で受け位置に用意します。後で保持できなくなる配置を避けます。

• 出力ホーン→ホーンスペーサー→クランクの順に、4穴を合わせます。

• 図の手前から見た重なり順は「ねじ頭 → クランク → スペーサー → ホーン → モーター」です。スペーサーは正面図ではクランクの背後に隠れます。

• B1を4本、クランク側からホーン側へ通す設計です。穴の合わない位置へ無理に締め込みません。

• ホーンとクランクの相対位置を写真で残します。CADの中間姿勢をモーターの絶対角とみなさず、サーボ軸を無理に手回ししません。

確認： ホーンへのねじ込み深さと底付き、実ねじ山の適合、スペーサーの座りを実物で確認すること。メーカー資料を基にした既存台帳ではホーンの最大深さは3.5 mmですが、必要な最小かかりや締付トルクは未確定です。

手順4／左右スライダと捕捉ナットを配置する

使用：左右スライダ各1。N1＝M2ナット、厚さ1.6 mm、6個（スライダ支点2＋爪固定4）。この手順で新しく使うボルト・座金なし。

• 左右スライダの支点用ナットを1個ずつ、爪固定用ナットを2個ずつ受け位置に入れる計画です。

• 正面図の奥がナット側です。背面図では見ている方向が逆になるので、Lが画面左・Rが画面右になります。ナットの受け位置と向きを背面から確認します。

• 爪をまだ付けず、スライダを枠の前方から収めます。

• 内側のシューが中央を向き、左右が逆になっていないことをCADと照合します。

確認： ナットが受け位置に入り、工具で対向保持できること。既存検証では支点ナットの保持を補助するベンチ治具候補がありますが、実保持・組付けは未確認です。接着でナットを固定する方法は本書では指定しません。

手順5／左右リンクを印刷肩に掛ける

使用：リンクL/R各1。この手順で新しく使うねじなし。

• 左リンクを左側のクランク支点とスライダ支点、右リンクを右側の2支点に配置します。

• リンクの大きい穴は、ねじ軸だけで支える穴ではなく、印刷された肩に掛ける構造です。

• 指先の爪や上下押さえはまだ付けません。支点の背面へアクセスできる状態を保ちます。

確認： 4箇所ともリンクが肩に掛かり、左右の部品がCADと同じ組み合わせになっていること。次の手順の図は抜け止めまで配置した状態です。

手順6／4支点の抜け止めを取り付ける

使用：B3＝ねじ径2 mm、長さ10 mm、2本。B2＝ねじ径2 mm、長さ8 mm、2本。W2＝厚さ0.5 mmの大径座金、4枚。N1は手順3・4で用意した計4個を使用。

クランク側のボルトは長さ10 mm、スライダ側は長さ8 mmです。どちらも頭を除く長さです。

支点ねじ径長さ（頭を除く）左右それぞれの組み合わせ合計
クランク→リンク2 mm（M2）10 mmB3＋大径座金W2＋M2ナット各1組、計2組
スライダ→リンク2 mm（M2）8 mmB2＋大径座金W2＋M2ナット各1組、計2組

ねじ頭→大径座金→印刷肩の端面→本体側のナット、という荷重の受け方を狙った構造です。リンクは肩の周りで回り、大径座金が抜け止めになります。座金でリンク自体を挟み込んで固定しません。

ねじの名目向き： 正面図の手前（爪側）から奥（モーター側）へ。ナットは奥側の本体にあります。模式図の矢印は軸の向きを説明し、実際の工具・部品が通る挿入経路を保証するものではありません。

確認： 座金が肩に座り、リンクを締め付けていないこと。W2を小さいW1に置き換えないこと。規定トルク、ねじの実かかり、ナットの対向保持、締結後の回転自由度は実物確認が必要です。「回るまでねじを緩めて放置する」を完了条件にしません。

手順7／上下押さえを固定する

使用：B4＝ねじ径2 mm（M2）、長さ12 mm、4本。N1＝厚さ1.6 mmのM2ナット、4個。W1＝厚さ0.3 mmの通常座金、4枚。押さえU/D各1。

ボルトの長さは12 mmです。頭は含みません。上の押さえに2本、下の押さえに2本使います。

• 本体枠の上下に押さえを1個ずつ配置します。

• 各押さえをM2×12の2本で固定する設計です。4本それぞれに通常座金W1を1枚、ナットN1を1個使います。

• ねじ頭→W1→押さえ→枠→ナットの位置関係をCADと照合します。

• 固定版の正面図で、上の押さえはCAD名 PG3_cap_D、下は PG3_cap_U。各2本のB4で計4本です。

確認： 押さえが正しく座った状態でスライダが拘束されないこと。引っ掛かりを、ねじを未締結のままにすることで解消した扱いにしません。締付トルク・造形公差は未確定です。

手順8／左右の延長爪を固定する

使用：B5＝ねじ径2 mm（M2）、長さ16 mm、4本。W1＝厚さ0.3 mmの通常座金、4枚。N1は手順4で用意した爪固定用4個を使用。V2の爪L/R各1。

ボルトの長さは16 mmです。頭は含みません。右爪の根元に2本、左爪の根元に2本使います。

• 把持面が互いに向き合うように左右の爪を置きます。

• 各爪の根元にM2×16を2本、通常座金W1を2枚使います。

• ねじ頭→W1→爪の取付腕→スライダ側の捕捉ナットの配置です。

• 各図の引出線は見えている側のねじ頭に合わせています。Rを確認してから反対側図でLを確認し、各2本・合計4本を照合します。

• 4本の穴位置は延長前の根元位置を維持します。+20 mmの先端側に穴を移しません。

確認： V2の延長爪を使い、左右のナットが空回りせず、爪の根元が浮いていないこと。爪先のたわみ・強度・250 g保持はこの組立図では確認できません。

手順9／左右パッドを貼る

使用：28×20×1 mmのパッド×2。新しいねじなし。

• 左右の内側の把持面へパッドを1枚ずつ配置します。厚さ1 mmは接着層を含みます。

• C9の配置基準は爪先端から1 mm内側、高さ方向中央です。V2ではパッドも爪の延長と同じ+20 mmだけ前へ移動しています。

• 先端へねじを追加せず、左右のパッド位置をCADと照合します。

確認： 左右で厚さ・位置が揃い、開閉部へ接着剤が入らないこと。シート材・接着剤・保持性能は未選定／未確認です。
