# 実物写真とマニュアルの版照合

2026-10-03。利用者提供の写真から見える特徴と、リポジトリ内のCADを比較した。
写真の公開はこの保存物に含めていない。

| 部分 | 写真から有力な候補 | 判別根拠・限界 |
|---|---|---|
| グリッパの爪 | PG3旧C7 | 細い接触板と窓のある形。C9/V2の全面板・補強形状とは異なる。刻印等による厳密な版同定ではない |
| アーム | R3に近い系列 | 曲がった肩部、長い矩形の延長、末端の平板クランプ形状。物理motor IDとの対応は未確認 |
| D405ホルダー | 長いR5に近い系列 | 広いD405取付板と長い矩形ループ。台上の写真だけでは俯角65°/75°を厳密には判定できない |
| 手元のP05配線窓 | 窓なしの旧支持部 | 利用者の観察。最新V2の窓が手元部品にあるとは扱わない |

爪の前後長のCAD比較値：C7は12.1 mm、C9は28.0 mm、低背V2は48.0 mm。
C7→C9の変更は爪2個・スライダ2個。旧品に本書のパッド・爪形状を自動的に適用しない。
ホルダー背面の取付座が見えないため、実物の板厚・座繰り・ねじ有効かかりは写真から確定していない。

P05はID4からID5を支えるアーム側部品であり、グリッパ11部品＋カメラ2部品の
既存 `set2all.gcode` には含まれていない。グリッパだけを交換しても支持部の窓は増えない。
