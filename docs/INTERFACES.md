# 組立・座標・機能インターフェース契約

## 1. 実機とモデルの対応

同梱旧アームは混在版、全XL430チェックポイントは6モーターoccurrenceを持つ。
実機の「ID4、ID5」の2個を、モデル内のJ4/J5やURDF連番に自動対応させない。
`specs/project.yaml` の `physical_to_cad` はまだnullである。

旧解析コードでの参考候補は次の通り。**同定結果ではない**。

| 旧解析上の役割 | occurrence候補 | 相手候補 |
|---|---|---|
| wrist | J3_XL430_00_DC11_A01_DUMMY_1 | KEEP_117_static_side_1 |
| gripper | J5_GRIPPER_XL430_00_DC11_A01_DUMMY_1 | KEEP_116_moving_side_1 |
| elbow | J4_XL430_00_DC11_A01_DUMMY_1 | KEEP_160_connector_1 |
| extension | J6_XL430_00_DC11_A01_DUMMY_1 | KEEP_057_shoulder_rotation_1 |

原本URDFは `Revolute 6` がgripper-staticへの接続、`Revolute 7` がmoving側への接続を表す。
これはソフト記述の関係であって、EEPROMのIDを観測したものではない。
同梱URDFは接続調査用でメッシュ一式を含まない。起動可能なシミュレーションではない。

同定レコード必須項目: physical_id / 写真の指示位置 / モーター型番 / STEP SHA /
root〜leaf occurrence path / shape index補助 / 対応link / source-to-world行列 /
output vs idler側 / 観測者 / 日時 / 確度。名前だけではPASS不可。

## 2. 座標規約

長さmm、角度rad、質量kg、力N、トルクN m。図面degは明示変換する。
すべて右手系。`T_A_B` はB座標をA座標へ写す4×4同次変換で、列ベクトルに左乗算。
`p_A = T_A_B p_B`、`T_W_C = T_W_G T_G_C`。回転行列はR^T R=I、detR=+1。
ミラーは剛体回転でない。鏡像形状を黙って姿勢行列として使わない。

| frame | 定義 |
|---|---|
| W | 保存アセンブリ世界座標。STEPから記録し勝手に原点を変えない |
| M4 | ID4出力軸と出力座面を基準。+Zは出力側へ、+Xは明示した穴/稜線で位相固定 |
| L45 | ID4出力に固定される支持リンク。ID5ケースの保持側を含む |
| M5 | ID5ケースに固定された基準。回転出力と区別 |
| H5 | ID5出力ホーン。M5からq5で回る。home/符号/offsetを明示 |
| G | 固定グリッパ枠。X=両爪開閉、+Z=把持域への接近、Yは右手系で決定 |
| C | カメラ光学座標。+Z=光軸前、+X=画像右、+Y=画像下 |

出力側座面の実座標はモーターCAD/実物から採る。既知の全厚34から±17が座面と決めない。
ケース固定Gと回るH5を混同すると、カメラも開閉と一緒に回ってしまう。
初期案はカメラをGまたはL45へ固定し、可動爪に載せる案は必要性がある場合だけ別評価する。

## 3. 機能別の接続表を実装する

| 接続 | 拘束/自由度 | 要検証 |
|---|---|---|
| ID4出力 → L45 | ボルト固定 | 軸、四穴位相、座面、トルク伝達、工具 |
| L45 → ID5ケース | 固定、ケース変形を抑える | 支持幅、ケース用ねじ、プラグ、挿入経路 |
| ID5ホーン → 駆動部 | q5と共回り | 中心ねじ保持、四穴の掛かり、出力側取り違え |
| 固定枠 → 左右爪 | 各々の並進、相互同期で機構全体1DOF | 横荷重支持、脱落防止、摩擦/ガタ、端停止 |
| 固定枠 → カメラブラケット → カメラ | 取り外せる固定 | 姿勢再現性、工具、保持、レンズ/端子クリアランス |

中心ボルトを締める力を可動リンクへ直接流して回転を固めない。
肩ボルト/軸受/金属スペーサ等を選ぶ場合、軸方向スタックと荷重経路を図示する。
新しい不要穴は作らない。各穴へ `feature_id`, 機能, 相手部品, 規格, 座面, ドリル方向,
深さ, 必要性を付け、用途を説明できない穴は設計保留とする。

## 4. カメラ取付契約

ユーザーが要求したのはカメラ搭載能力であり、特定カメラの採用ではない。
ブラケットはグリッパ枠との標準側インターフェースとカメラ固有側を分離する案を比較する。
標準側もまだ寸法未定。架空の「ユニバーサル四穴」を製作確定しない。

カメラ台帳: 型番/改訂、ケースor裸基板、外形と高さ、穴とKeep-out、レンズ突出、
センサ光学原点、HFOV/VFOVまたは校正K/distortion、作動距離・近接限界、質量/重心、
コネクタと抜き差し方向、ケーブル径/曲げ半径、ねじ・工具、放熱・通気。

視野条件: 作業距離範囲と開口min/mid/max、ID4の代表/端姿勢で指定対象領域ROIを投影。
歪みを無視したpinholeの場合はその適用限界を記載し、近接は実カメラで検証する。
frustum内にあるだけで可視としない。爪/リンク/把持物による遮蔽をray/深度で検査。
視線が塞がる把持完了状態を許すか、爪先と対象中心のどこを見たいかをQ-02で確認する。

## 5. 締結台帳とBOM

ねじ1種類のBOMと、それを使う各配置のinstance台帳を分ける。
型番/規格/径/ピッチ/首下長/頭/工具/数量/実物確認/購入状態をBOMへ。
各instanceは source/target feature、座面、ワッシャー厚、板厚、公差、
有効掛かり上下限、底余裕、締付根拠、回り止め、工具アクセス、組立順を持つ。

寸法連鎖はL首下 - 積層厚 = 穴への突入量。ただし突入量は有効ねじ掛かりとは限らない。
最悪公差で「短すぎる」と「底突きする」を別々に検査する。
CAD内の工場ねじを外付けBOMへ二重登録しない。代替支持案を同時採用しない。
