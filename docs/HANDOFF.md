## 依頼の核心

既存アーム先端にXL430-W250-Tによる平行グリッパを検討する。
**ID5はロール専用に予約しない。役割変更をCADモーターの自動削除に読み替えない。**
ID4とID5の間の支持リンク、および把持域を見るカメラの搭載も一緒に設計する。
グリッパ単体を机上で完成させても、アームに締結できない・カメラで見えないなら未達です。
カメラは未購入、28x28 mm四穴。ID5モーター上方から把持域を斜め下向きに見ることを希望。
把持物はキューブ、辺長/重量未定。
P05局所配線逃げ候補作成は許可済み。付属M2.6x5ねじはない/不明。
原本・既存穴・締結/接触面・支持機能を保持し、印刷/通電は別承認。

参考は [Mini Max](https://www.robotandchisel.com/2011/07/01/new-gripper-for-mini-max/)
の1サーボで両爪が平行移動する構成と、
[Robonine](https://github.com/roboninecom/SO-ARM100-101-Parallel-Gripper)
のカメラを搭載できる構成。モーターはユーザー確認済みのXL430です。
AX-12やSTS3215の穴寸法、性能、制御手順を流用しないこと。

## 前の作業から持ち込む重要な事実

旧アームの作業では、穴周囲の円形化という局所要求を満たそうとして元形状を大きく壊し、
干渉や締結不良が残っても部分テストから完成を宣言した。これは今回繰り返さない。
ユーザーの実機でも支持幅不足によりリンクが両側からホーンを押し、拘束・過負荷が疑われた。
トルクを上げるのではなく、座面、支持幅、回転支持と締付荷重の分離をCAD/実物で確認する。

旧チェックポイント `low_cost_robot@6d56bfe` は**全体未承認**。
全XL430候補には保存姿勢で46組の外部干渉が記録されている。
元STEPの一部は `isValid()` が真でも独立コピーとのBoolean同一性対照が不成立だった。
この数値は同梱旧記録の報告であり、本リポジトリで全走査を再実行した値ではない。
同梱STEPは調査材料であって、製作の正解形状ではない。

## 最初の実行順

1. `AGENTS.md` と本書の次に、REQUIREMENTS / DESIGN_BASIS / INTERFACESを読む。
2. `rtk proxy uv sync --locked`。入力は`references/`に保存し、原本を編集しない。
3. `rtk proxy env MUJOCO_GL=egl uv run pytest -q`。診断CLIはREADMEとPG2レビュー参照。
4. `temp/workdoc_Sep24-2026_pg3_id5_only.md`を現在の実行計画、
   `docs/PG3_ID5_ONLY_DESIGN.md`を仕様とする。Sep23の作業書は旧配置の履歴。
   以前の`temp/workdoc_Sep22-2026_all_xl430_gripper_camera_calibration.md` §8は履歴。
   過去の全DoD達成は撤回済み。存在しないTOY_PROBLEM/WORK_PLAN/verify_assetsは前提にしない。
5. **最初の設計課題はモーターID対応の確定**。同梱の内部ラベルからID4/5を推測しない。
   必要ならユーザーに該当モーターと接続リンクの写真への指示を依頼する。
6. カメラ設計は`docs/CAMERA_MOUNT_ID5_CORNER.md`と
   `specs/camera_mount_id5_corner.yaml`を入口にする。既存`camera_jig/`と
   `specs/camera_mount.yaml`はP05側方案の履歴で、ターゲット実装として再利用しない。
   XL430のケース角ねじが構造マウントに使えるか、ねじスタックとケース機能を先に調べる。
7. カメラ・把持物・開口幅・荷重等を確認し、未決のまま進められる概念比較と、
   未決なら止める製作寸法決定を分離する。

## 次の担当者が作る成果物

- 実機IDとCAD occurrenceの対応表、ID4出力からID5ケース・ホーンまでの座標/取付契約。
- 機構案の比較と選択理由。パラメータ、構成部品、機能穴、荷重経路、組立順序。
- モーター/ホーン/ねじ/ナット/ワッシャー/軸受/カメラ/配線を含む実寸CAD。
- 幾何保存、締結、工具、干渉、可動域、視野、荷重、印刷に対する検証結果と不良対照。
- 同一姿勢の正投影画像、DOMとB-repの対応、全体アーム表示、独立レビュー。
- 製作に進む場合のみ、承認された部品のSTEP/STL、BOM、組立説明、印刷条件と実測項目。

## 判断・権限の境界

CAD検討と診断用出力は進めてよい。未知のカメラを買ったことにする、型番未決のねじを
「締結済み」にする、既存アームの未解決干渉を隠す、通電して検証することは不可。
物理試作と実機駆動はユーザーと段階を分ける。設計エージェントの機種名や役割が変わっても
同じ受入基準を使う。今回別エージェントは起動していない。

## 引継ぎ完了と設計完了を分ける

本引継ぎの完了 = 要求・設計基準・作業書・ローカルスキル・小課題・参照CADが利用できること。
グリッパ設計の完了 = REQUIREMENTSのD-01〜D-10を満たしたこと。
前者の達成を後者へ読み替えない。
