# カメラ取付・購入候補と確認項目

2026-09-24。未購入。参考相当の28x28 mm四穴取付を維持して設計を進める。
28 mmは穴中心間隔であり、基板外形・質量・光学仕様を決める値ではない。
ロール不要へ要求変更済み。対象はキューブ、辺長/重量は未定。

## 参照と候補

[Robonine Step 9](https://github.com/roboninecom/SO-ARM100-101-Parallel-Gripper/blob/305ad0f6e8f19e4e739616160cbdc7cae1ab153f/docs/assembly-guide.md#step-9-camera-attachment-optional)
は28x28 mm穴のUVCカメラ、スペーサ、M2ねじを指定しているが、カメラ製品型番は指定しない。
参考のM2x8を本設計の板厚/スペーサへ無検証で流用しない。

購入調査候補としてArducam A219を確認した。まだ取付適合品として推奨/採用していない。
[メーカー仕様](https://www.arducam.com/4k-8mp-imx219-autofocus-usb-camera-module-with-microphone-1080p-mini-uvc-usb2-0-webcam-standard-module.html)
にはB029202とB0292-1の比較があり、前者は32x32 mm基板/ケースあり、後者は38x38 mm基板/
ケースなし。垂直画角も50度と47度で異なる。両者の焦点範囲下限は10 cmと記載。
同じ商品ページ名だけで外形や光学値を混同しない。
ページ本文では28x28 mm穴ピッチを確認できていないため、図面/供給者確認が必要。
この段階で注文しない。メーカーのCAD/図面で穴位置、部品高さ、端子位置、質量を確認してから
採用判断する。32 mm角基板だから28 mm穴だろう、という推定は禁止。

## 新配置での確認順

1. ID5で開閉する配置と、既存P05に残す支持面を確定する。旧r5の視点を流用しない。
2. 試験用キューブ10/20/30 mmを比較候補とし、両爪・把持域・対象物の見え方を検証する。
   寸法は提案でありユーザー要求ではない。重量/材質/摩擦係数も未設定。
3. 各SKUの実図面を取付板に重ね、四穴中心、レンズ突出、基板裏部品、プラグ挿抜を確認する。
4. 実際の映像モードでの水平/垂直画角と焦点距離条件を使って視点を選ぶ。
   旧仮FOV50度や対角画角を垂直画角に置換しない。100 mm未満なら近接焦点の適合を再選定。
5. ねじ頭・ナット・スペーサ・工具・USB配線とPLA支持荷重を同じ版で検証する。
6. 購入後は寸法/質量、無負荷の保持、実映像の焦点/遮蔽、ケーブルの無理な曲げを確認する。

キューブ候補の根拠: `gripper_design.pg3.opening_mm`による公称開口は
25度で48.8951 mm、135度で0.9274 mm。10/20/30 mmに一致する角度はそれぞれ
103.4870/82.1472/64.2593度。式上の一致だけで爪接触、保持力、実寸法を承認しない。
