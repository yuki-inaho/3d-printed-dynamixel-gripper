# 要求・制約・完了条件

2026-09-24更新: ロール不要。先に回答された正面から左右30度の要求は、後続の
「ロールなくて良い。全部グリッパ用で良い」で取り下げ。ID5開閉用・追加モーターなしを
ユーザー確定。実機IDとCAD番号の観測対応は未確認。r5は旧配置の検証履歴。
カメラ未購入でもSO101参考相当28x28 mm四穴を維持し、ID5モーターケース角ねじを
利用してモーター上から把持域を斜め下向きに見るカメラ配置を新規検討する。
旧P05側方マウントはユーザーの視覚的期待に合わず、現要求の受入候補ではない。
対象はキューブ、一辺・重量は未定。P05局所配線逃げ候補と再印刷案の検討は許可済み。
実印刷・通電の承認ではなく、原本・既存穴・締結面・接触面・支持機能は保持する。

## 1. コンセプト

「手元のアーム先端で、対象物を両側から安定して掴み、その把持域を手元カメラで見られる。
自分で3Dプリントし、実際に組み立て・締結・配線・保守できる」ことが目的。
見栄えだけのCAD、局所穴だけの合格、別アーム専用部品のコピーでは目的を満たさない。

## 4. 範囲と非ゴール

対象: ID4の出力インターフェース、支持リンク、ID5固定部と回転出力、伝達機構、案内/爪、
カメラ取付/視野、締結、配線、上流へ追加される荷重。
ID1〜ID3本体の再設計は非ゴール。ただし干渉・肩保持トルクへの影響は検査する。
ホーン中心固定ねじは回転出力の四穴と別。idler側を根拠なく回転駆動側にしない。
新ソフトの実機制御、電源操作、購入、量産・安全認証は今回の引継ぎ範囲外。
