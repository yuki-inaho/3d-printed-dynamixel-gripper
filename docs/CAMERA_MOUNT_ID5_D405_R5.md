# ID5上方カメラ台 R5（RealSense D405対応・俯角65°）

更新: 2026-09-24。版 `ID5-CAM-R5-D405-P65`。**CAD上の設計候補**であり、印刷・実機装着・通電の承認ではない。
生成物: `outputs/camera-mount-id5-overhead-d405-r5/`。生成コード: `gripper_design/camera_overhead_d405_r5.py`。

## 1. 依頼と結論

依頼は次の3点。

1. RobonineのSO-ARM100/101平行グリッパーと同様に、D405用の取付穴を設ける。
2. 首下げ角度を参考設計と同等程度にする。
3. その後の追加指示: D405でいい感じに見えるよう調整する。角度は5°刻みのきりの良い値にする。

結論は、光軸を**グリッパー進入方向(+Y)から下へ65°**とし、D405の2×M3穴と従来の28 mm四穴を併設した交換式取付板で構成すること。
65°はRobonineの30°と同じではない。理由は§3のとおり、PG3の形状では30°だと爪がフレームの陰に入るためである。

## 3. 俯角の数値比較（なぜ30°ではないか）

| 対象 | 光軸と進入方向のなす角 | 取得方法 |
|---|---:|---|
| Robonine `RB9.01.062.000 Gripper.STEP` | **30.0°**（把持部側へ） | レンズ円筒軸 `(0,−0.5,0.866)` と爪の伸びる方向+Zから実測 |
| Robonine `RB9.01.060.110 D405 holder.STL` | 30.0° | 取付板の平面法線 `(0.866,0.5,0)` と取付面の法線Xから実測 |
| R4-C2 | 63° | 仕様値 |
| R7 | 30° | 仕様値 |
| **R5（本版）** | **65°** | 生成したB-repから実測（テストで確認） |

Robonineの爪は、フレーム前面から約62 mm先まで伸びている。一方PG3は、パッド（y 204.6〜224.6、z 150.6〜178.6）の直後に、フレームとキャップの壁（y 181.9〜192.3、上端z 192.6）がある。
パッドの後ろ下端をこの壁越しに見るには、約70°の見下ろしが必要である。光軸30°ではD405の垂直視野の半分29°を足しても59°までしか届かない。

角度ごとの可視率（パッド内面、箱モデルでの概算、深度70 mm以上を条件）は次のとおり。

| 光軸角 | 可視率 |
|---|---|
| 30° | 最大67%（カメラを90 mm持ち上げても頭打ち） |
| 40° | 83% |
| 50°以上 | 100% |

5°刻みの候補で、深度75 mm以上（Min-Zに5 mmの余裕）を条件に最適化した結果は次のとおり。

| 光軸角 | パッド・キューブ可視率 | 最小深度 | マスト高 |
|---|---|---:|---:|
| 60° | パッド100%、キューブ96% | 81.9 mm | 56.6 mm |
| 65° | 両方100% | 75.1 mm | 48.3 mm |
| 70° | 両方100%（画像中心寄り） | 75.0 mm | 47.0 mm |

65°は、斜めに見下ろす見え方と、画像上部に前方の接近先が映ることを優先して選んだ。70°にする場合は `Spec.pitch_deg=70` と `glass_center=(-0.2,196,254)` に変えて再生成し、再検証する。

## 4. 構成と寸法

新規印刷部品は2個。

| 部品 | STL | 外形 | 内容 |
|---|---|---|---|
| ベース | `STL/01_ID5_top_base_D405.stl` | 61.4×24.4×73.3 mm | ID5上面の外部取付穴4個（φ2.1 DP4、16×12 mm）で固定する足と、D405の外側を通る左右の支持壁（厚さ8 mm、内面は±22.5 mm） |
| 取付板 | `STL/02_D405_carrier.stl` | 63×54×4 mm | D405用のM3スロット2個（中心間20 mm）、UVC用の28×28 mm・φ2.4の四穴（別途スペーサーが必要）、M3タイボルト穴2個 |

- **D405の取付**: 背面のM3×0.5（中心間20.00 mm）にM3×6六角穴付きボルトを使う。座ぐり後の板厚3 mmで、侵入は3.0 mm。図面の最大4.0 mmに対して1.0 mmの余裕がある。
  - 穴の上下位置は図面に寸法がない（画素計測では中心から±0.6 mm以内）。このため、推定値を確定扱いせず、上下±1 mmのスロットにした。
- **USB**: D405はUSB 3 Micro-Bを側面に持つ（コネクタ中心は背面から6.82 mm）。
  - 正立で取り付けると−X側にプラグが出る。プラグは26 mm長の包絡、ケーブルはφ4.5×15 mmの仮包絡とした。
  - 支持壁は板の下部（像の上下方向v ≤ −11 mm）にだけ接続し、プラグ帯（±8.5 mm）との離隔を3 mm以上確保した。
  - 180°反転して取り付けても同じ離隔になる。
- **光学原点**: データシートに基づき、深度原点はガラス面の3.7 mm内側、左右イメージャは±9 mm（基線18 mm）とした。
  - ガラス中心は世界座標(−0.2, 197, 257) mm。
- **質量**: 印刷部品は中実PLA換算で約45 g、D405は58 g（±10%）。手首に約0.1 kgが載る。
- **組立順**:
  1. ベースを上面の4穴にタッピンねじで固定する（ねじの侵入2.5 mm、底まで1.5 mm。R4-C2と同じ積み重ね）。
  2. 机上で、取付板にD405をM3×6で固定する。
  3. M3ナットを支持壁の外側スロットから入れ、取付板をタイボルト2本で固定する。
  4. USBを−X側から差し込む。

## 5. 検証結果

| 項目 | 結果 |
|---|---|
| 入力 | `ID5_mid_P05_windows_CANDIDATE.step`（SHA-256 `102031f3…`）。旧 `CAMERA_` 21要素を外し、236要素を保持 |
| 保存組立 | 開・中・閉の3姿勢とも257要素。再読込時の在庫・体積・外形が一致 |
| 元形状の保存 | 236要素すべてで体積・面積・外形の誤差が閾値内 |
| 上面4穴 | モーターのB-repとベースの穴軸を独立に抽出し、4点とも一致 |
| 新部品同士 | 210組すべてPASS。M3とD405のねじのかみ合いは、データシートの穴軸・深さ4.0 mmのROI内に限って許容 |
| 既存全腕との静的干渉 | 4,956組すべてPASS（最小隙間0.3 mm、材料交差を先に判定） |
| 開閉221姿勢（25〜135°、0.5°刻み） | 失敗0、最小隙間15.4 mm |
| STL | 2部品とも1ボディ、watertight、巻き方向が一貫 |
| テスト | R5の22件と、取り込んだR4-C2の29件、計51件がPy3.12/CadQuery 2.7環境で合格 |

視野はD405の両イメージャで確認した。H84°、1280×720でレンダリングしたため、垂直は53.7°となり、公称58°より保守的である。

| 状態 | R5（65°） | R7の視点（30°） | R4-C2の位置にD405を付けた場合 |
|---|---|---|---|
| 空・開/中: 爪の可視率 | 98.8〜99.6%、画面内100% | 69〜71%、画面内47%（画面端で切れる） | 88〜94%、画面内63〜100% |
| 空・開/中: パッドの可視率 | 100% | 79〜82%、画面内75% | 100% |
| キューブ10/20/30 mm | 92〜100%、全体が画面内 | 66〜84%、画面内75% | 87〜100% |
| 最小の光軸方向深度 | 71.9 mm（爪）/ 74.9 mm（キューブ） | 70.2 mm | **40.2 mm（Min-Z未満）** |
| 取付部による遮蔽 | 0画素 | （自身の取付部は評価に含めていない） | （同左） |

**ID4（手首ピッチ）の可動域への影響**を2°刻みのサンプルで調べた。回転軸は、M04ホーンのB-repから実測した (y=104.9, z=164.6) mm、X軸方向である。

- カメラ台なしの既存アームは −138°〜+128° まで回る。両端ともP05がP04に当たって止まる。
- R5を付けると −138°〜**+110°** になる。+112°で取付板がM03（肘）に当たる。
- つまり、グリッパーを上へ折り返す側で約18°狭くなる。下側は既存の制限の方が先に効く。

ID4の実運用範囲の出典がないため、この制限を許容するかどうかは未判断である（`reports/id4_sweep.json`）。

閉状態ではパッド同士が互いを隠し、把持中はキューブがパッドを隠す。これは対象物自体による遮蔽であり、取付部による遮蔽とは分けて記録した。
画像は `images/camera/`（R5）と `images/camera/REF_*`（比較視点）にある。数値は `reports/camera_views.json`。

## 8. 再現

```bash
uv run python -m scripts.build_camera_overhead_d405_r5      # 部品・STL・3姿勢の組立
uv run python -m scripts.validate_camera_overhead_d405_r5   # 干渉・保存・STL
uv run python -m scripts.camera_view_d405_r5                # D405の視野と比較視点
uv run python -m scripts.id4_sweep_d405_r5                  # ID4の可動域への影響（診断）
uv run pytest -q tests/test_camera_overhead_d405_r5.py tests/test_camera_overhead_*r4.py
```

R4-C2のソースは、ZIP（SHA-256 `f2c6b7b3…`）から無変更で取り込んだ。対象は `gripper_design/camera_overhead_r4.py` と、`scripts/*_r4.py` のうち build/validate/camera_view/service/continuous の5本。R5は、そこから検査関数と締結部品の形状関数を再利用している。
