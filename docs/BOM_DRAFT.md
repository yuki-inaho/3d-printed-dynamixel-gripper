# PG3 r5 末端BOM草稿

> 現行の構成（ID5-only の PG3 ＋ D405 カメラ台 R5 ＋ アーム R3）の締結部品は [FASTENER_BOM.md](FASTENER_BOM.md) を参照。本書は r5（P06 支持部・P05 側面カメラ）の履歴。

2026-09-23。**数量照合用。購入表・印刷リリースではない。**
対象はPG3 C92 J28 C9、改修P06、P05固定カメラホルダの追加/交換部品。
機械可読の正本は`specs/pg3_candidate_bom.yaml`。r5 mid STEPのSHAを固定している。
旧ラック案/PG2を混ぜない。上流ID1〜5、既存P05、モーター内部部品、配線は下記数量に含めない。

## 数量と形状の境界

- r5の309 occurrence中、末端95 occurrenceを全件・重複なしで照合。
- 実体品目94個: 印刷候補16、パッド2、モーター/カメラ各1、ねじ34、ナット20、座金16、金属スペーサー4。
- `PG3_XL430_fixed`と`PG3_XL430_horn`は**モーター1台の表示分割**。2台を発注する意味ではない。
- r5は実機未承認。95要素の数量一致は、ねじ規格/形状/強度/配線/製作公差の合格ではない。
- M05/物理ID5のロール候補を爪開閉へ転用しない。実機IDとCADラベルの対応は未確定。

## 別途必要なものと組立条件

- jaw駆動XL430-W250-T一式1台。既存M06を使うか追加するかは実機対応で確定する。
- カメラ1台。28×28 mmは**取付穴ピッチの参照値**で、カメラ外形寸法や実型番の指定ではない。
  2026-09-24に未購入/同等取付での継続を確認。[購入調査と確認項目](CAMERA_SELECTION.md)。
- USB/TTLケーブル、プラグ、ストレインリリーフ、結束具、E148/電源の条件は未確定。
  現在の候補配線はP05に干渉するため、配線済み部品表としては未完成。
- bench用治具は`outputs/pg3-bench-support-r1/`の別候補。装着品16個には含めず、
  印刷・使用を承認していない。組付け時に17部品の機構と別体spacerを保持する手段が必要。
- 公称順序は4支点をbench先組み→frameへ搬入→ホーン締結→押さえ/爪/パッド。
  カメラは交換板へ先付けし、ホルダを後からP05へ固定する。締結後に全工具が入るとは限らない。
- 1.5 mm六角モデル、L型工具候補、ケースねじのドライバ、M3ナット工具の実寸は
  `PG3_INSTALLATION_CANDIDATE.md`の各工程条件と照合する。工具名だけでアクセス合格にしない。
- 未購入の部品を「組付け確認済み」にしない。実ねじ/工具、配線、カメラ、PLA仮組みが揃うまでrelease=false。

## 再照合

```bash
rtk proxy uv run python -m scripts.check_pg3_bom \
  outputs/pg3-installable-candidate-r5 \
  --out outputs/UNUSED-pg3-bom.json
rtk proxy uv run pytest -q tests/test_pg3_bom.py
```

exit0は数量台帳の整合だけ。別版STEPは入力SHAで拒否する。新設計へ適用する際は
新しい版と数量をレビューし、台帳を更新する。旧ラック案/PG2は
`REVIEW_PG2_AND_SELF_AUDIT.md`、過去のjaw締結台帳は
`specs/jaw_fastener_ledger.yaml`を履歴として参照する。
