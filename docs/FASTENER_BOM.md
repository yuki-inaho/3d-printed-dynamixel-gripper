# 締結部品表（ID5-only PG3 ＋ D405 カメラ台 R5 ＋ 全 XL430 アーム R3）

2026-09-25。**CAD 上の締結位置から数えた部品表の下書き**であり、購入承認・組立承認ではない。
数量は1台分。2台作るなら2倍にする。単位は mm。

対象構成は次のとおり。

- ID5 だけで開閉する PG3（`docs/PG3_ID5_ONLY_DESIGN.md`）
- D405 用の上方カメラ台 R5（`docs/CAMERA_MOUNT_ID5_D405_R5.md`）
- アーム R3 の ID1〜ID5（`references/arm-r3/`）

次は対象外。

- r5 の P06 支持部と P05 側面カメラの部品（`docs/BOM_DRAFT.md` の履歴）
- モーター内部のねじ、配線、机への固定

最大深さは「最小のかかり長さ」ではない。ねじの品番、ねじ込み深さ、締付トルク、工具が入るかどうかは、いずれも未確定。

| **小計** | | | **52** | | |

内訳は、M2（ホーン・アイドラ）28本、M2.6 タッピング16本、ケースねじの交換8か所（規格未確定）。

- **その他に必要なもの**:
  - アイドラ HN11-I101 を3セット（M02・M03・M04 用）。ねじがセットに付属するかは要確認。
  - ホーンはモーターの付属品を使う。
- **ねじ長の目安の計算**: 板厚＋ねじ込み量。ホーン・アイドラは深さ 3.5 以下、φ2.1 の下穴は 4.0 以下に収まるよう計算した。座金を挟む場合は長さが変わる。
- **座ぐり**: P03 → M03 の4穴は、どれも φ4.8 の座ぐり付き（深さ10.35 が2、0.55 が2）。深い2か所には軸の長いドライバーが必要。
- **締結先の分からない穴**: 台座の φ2.7 ×6 と、P05 の φ3.0 ×6 は、どのモーターとも対応しなかった（机への固定や基板の取付の穴の可能性）。数量には含めていない。
- **「要確認」の3行**: 台座と M02 のケースねじの交換、M01 のホーン側の板厚は、実物で確かめてから決める。

## 再現

```bash
uv run python -m scripts.survey_arm_fastener_sites --out outputs/UNUSED-arm-fastener-sites.json
```

同じ軸上の座ぐり（例: P03 → M03 の φ4.8）は、別の行として表示される。締結位置の数には、座ぐりではない方の穴（φ2.4 など）だけを数える。
