# ID5単独開閉 PG3 設計仕様

更新: 2026-09-24。状態: 設計・検証中、製作未承認。
作業手順と実績は `temp/workdoc_Sep24-2026_pg3_id5_only.md`。
本書は「何をどの構造で満たすか」を定義し、実行済み判定とは分ける。

## 1. 目的と確定要求

既存全XL430アームへPG3平行グリッパとカメラを装着できる状態にする。
ID5のXL430-W250-T一台で開閉する。手首ロール用の別モーターや追加ID6は使わない。
既存ID1〜4を消したり、ロール機構を残して単にソフト固定する解釈は採用しない。
カメラは未購入、SO101参考と同じ28x28 mm四穴を維持する。最新要求はID5モーターの
ケース角ねじ付近で支持し、モーター上方から把持域を斜め下向きに見ること。
旧P05側方マウントは視点が意図に合わず、新候補の採用案ではない。
対象は寸法/重量未定のキューブ。10/20/30 mmは比較用提案であり確定仕様ではない。
P05の局所配線逃げ候補と再印刷案は許可済み。原本/穴/締結・接触面/支持機能を保持。
付属M2.6x5ねじはない/不明。型番/頭/ねじ山/先端/有効深さを検証せず代用品を決めない。
実印刷・SD書込・通電・シリアル操作・購入は本作業では行わない。

## 2. 旧設計との相違

| 項目 | 旧r5 | 新候補 |
|---|---|---|
| ID5の役割 | ロール候補 | 開閉専用、ユーザー確定 |
| 末端駆動台数 | ロールと開閉の2台 | 開閉の1台 |
| PG3配置 | CAD M06位置 | CAD M05位置を幾何候補とする |
| P06/元P07 | P06局所改修を保持 | 下流モーターと共に撤去候補 |
| P05 | 未変更 | 支持機能維持、必要な配線逃げだけを別版で検討 |
| カメラ | P05固定の側方支持 | ID5モーターケース角ねじ付近に支持する頭上・斜め下向き候補 |
| 可動評価 | 追加ロール±30度を含む | ID4等上流姿勢と開閉。独立ロールなし |

ユーザーが確定したのは役割と台数。CADのM05という文字列が実機ID5の実測証拠にはならない。
次節の配置は新設計の採用候補であり、非通電実物照合ゲートは残す。
元r5を上書きせず、新しい出力ディレクトリと部品台帳を使用する。

## 3. 座標・配置契約

単位mm。アームは `references/arm-r3/arm_XL430_R3.step` の保存world座標。
PG3内部座標はX=開閉方向、Y=機構上方、Z=出力軸/指の延長方向。
候補変換は `world = Rx(-90deg) * local + (-0.2,164.9,164.6)`。
これによりZ出力軸はworld +Y、爪の開閉方向Xはworld Xになる。
供給モーターSTEPをこの変換で置き、元M05_ref00に有限形状署名を照合する。
さらに実取付穴/座面を照合する。署名一致だけで完全材料同等性やboltabilityを承認しない。

部品帰属契約:
- M01〜M04とP01〜P05等の上流部品は保存する。
- M06配下全要素、P06、P07を新候補の撤去台帳へ記録する。原本からは削除しない。
- M05_ref00はPG3のfixed/horn分割表示へ置換する。他のM05参照は原位置で保持する。
- 分割fixed/hornの2 CAD要素は物理モーター1台。隠れた2台目を許容しない。
- 新カメラ候補はID5モーターの固定ケース側へ支持し、開閉ホーンには固定しない。
  ケース角ねじが適切な取付点かは未確認。元CADのM05ラベルも実機ID5との観測照合を証明しない。
- 角度はPG3機構角25〜135度。実XL430絶対角/ホーム値との対応は未確定。

## 4. 支持・配線・締結

新配置ではID5ケースをP05が支持し、出力ホーンがPG3クランクを駆動する。
PG3フレームはケースに固定する。原P05とフレームの干渉があれば、P05の支持を
削って通すのではなく、重複する固定構造・ねじ・荷重経路から再設計する。
無断の支持幅変更や嵌合面移動、旧P06を非表示にするだけの浮遊組立は禁止。

配線は公式ケース出口/中空軸を起点とする。ケーブル断面/曲げ径は実品未確定。
既存のOD1.9/R1.2診断は製品保証値でなく、これだけで最小窓寸法を決めない。
窓候補ごとに変更mask・除去体積・保護面・最小残断面・丸み・組付順を記録する。
case cover内部の交差はP05を削っても解消しないため別扱いとする。
挿抜/先配線/最終配線状態/開閉時の屈曲を分離して検査する。
支えの連結性はCAD、PLA強度/クリープは荷重/材料/印刷条件と実物で検証する。

初期配線窓の比較候補: 左右の厚4mm側壁のみ。X[14.05,18.05]と[-18.45,-14.45]を
貫通し、YZ平面で中心線Y151.0、端部中心Z176.2/181.2、端部R1.5の丸長穴。
窓の幅3.0/全高8.0mm。旧診断OD1.9に対する側壁通過の名目隙間は0.55mm。
これは曲げ許容/プラグ通過/実ケーブルの最小寸法決定ではない。
穴中心群と元穴外周2.5mmの保護環、Y144.4以下のクランプ/連結板を切除しない。
原motor接触面の変化と荷重成立は別評価する。切除率だけで強度合格にしない。
この候補を新アームへ自動採用せず、単体・全体差分・配線残交差を保存する。
初案Y150.6は仮ケーブルがmotor rear coverに6箇所交差したため棄却。
Y151.0は線径/曲率/モーターを変更せず、側方脚と窓位置だけ0.4mm移動する候補。
仮ケーブル対カバーの公称隙間0.25mmを別検査する。実ケーブルの曲げ許容は未確認。

## 5. カメラと対象

取付ピッチは28x28 mm四穴で、基板外形やFOVではない。旧仮FOV50度は診断限定。
視点はID5ケース角ねじ付近の支持から、モーター上方を通して把持域へ斜め下向きに向ける。
角度や突き出し量は未決で、CAD上の視野比較を先に行う。旧P05側方位置を少し動かすだけで
要求を満たしたとしない。カメラの型番・実外形・光学中心・FOV・重量はnullのまま扱う。
キューブの実寸未定なのでまず10/20/30 mmの比較画像と遮蔽物帰属を出す。
画像に一画素でも見えることを実用可視性としない。キューブと指、パッドの遮蔽を分ける。
取付位置変更はカメラ実体/ホルダ/工具/ケーブルも追従させる。仮想センサだけを移動しない。
ケース角ねじの用途、ねじ長/有効かかり/ケース締結維持、頭への工具アクセス、組立順と
カメラケーブル経路を同じ候補版で調べる。これらが未解決なら取付・印刷承認を出さない。
候補型番/焦点/質量は `docs/CAMERA_SELECTION.md`。未購入でも設計作業は継続する。

## 6. 実装境界

新規 `gripper_design/pg3_id5.py` が配置/帰属を担当する。
`scripts/review_pg3_id5.py` が保存・再読込・対検査・画像・証跡を担当する。
既存 `gripper_design/pg3.py` の運動学と `pg3_crank_representation.py` の修正を再利用。
旧配置の `pg3_installation.py` は再現用として残す。
`simulation/pg3_scene.py` は既存配置を既定値として保ち、明示的なno-roll配置を追加する。
変更後のPG3実体を逆変換してmesh化し、元neutral形状へ暗黙に戻さない。
新sceneにはwrist_roll jointを作らない。非ゼロroll入力は拒否する。

## 7. 検証と受入

| 契約 | 負例 | 正例の証拠 | 合格の限界 |
|---|---|---|---|
| ID5単独 | 旧r5/残M06/ID6要求 | 数量・帰属・撤去台帳と5モーター構成 | 実機ID照合は別 |
| 座標 | 誤軸/1mmずれ | M05形状署名/穴中心/座面 | 材料同等性・締結別 |
| 原形保存 | 保護面侵入/余分な穴 | mask外差分0、単一正体積solid | 強度別 |
| 干渉 | 元干渉形状/配置ずれ | 全変更部品対全相手、ERROR/UNKNOWN保持 | 接触/公差別 |
| 運動 | stale mesh/残roll joint | 保存版mesh、開閉閉ループ/台数 | 力学別 |
| 可視性 | 指による対象隠れ | headless画像/segmentationと同一版DOM | 実optics別 |

DoDは要求書D-01〜10。部分検査が緑でも実機装着完了にはしない。
製作可能なBOM/全締結・工具・配線・強度・画像/仕様照合・非通電実物組付けが必要。
全体の未達を残したまま診断成果を出せるが、製作リリースは禁止。
